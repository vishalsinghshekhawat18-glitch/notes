## 4. Hard-Won Presentation & Engineering Standards

From previous implementations in Shelf 007, the following structural rules are strictly enforced:

1. **Zero KaTeX / SVG / Unrendered Syntax Leakage**:
   - Never leak raw KaTeX code, SVG paths, or unparsed math tokens into general markdown prose.
   - Use clean, standard Markdown typography and Unicode characters.
2. **Proportional & Beautiful Markdown Tables**:
   - Ensure table columns are proportioned relative to their textual density. Never create narrow, warped columns where one side wraps 8 lines and the other has a single word.
3. **Sequential Chapter Transition Chains**:
   - Every chapter must conclude with an exact navigational transition:
     `[Chapter X Complete ➔ Next: Chapter Y]`. Numbering must be strictly verified.
4. **Clean Heading Hierarchy**:
   - Use `# Chapter Title`, `## Section Title`, `### Concept/Waypoint`, and `#### Distinction/Evidence`.
   - This ensures the collapsible reader sidebar operates smoothly without squeezing content.
5. **Print-Ready A4 Standards**:
   - Include clear page-break boundaries (`page-break-before: always` / `page-break-after: always`) where appropriate for print codices.
6. **Bilingual Sensitivity (Hindi-English Precision)**:
   - Specific Rajasthani cultural terms, administrative designations, and scheme names must provide authoritative Devnagari and Roman transliterations (e.g., *धमोचा (Dhamocha)*, *नातरा प्रथा (Natra Pratha)*, *पंचेवड़ा (Panchewada)*).

## 5. RPSC RAS Exam Alignment & Mark Architecture

All content is structured to serve both exam tiers:

- **Prelims Lens (Objective Sharpness)**:
  - Exact year, king, place, excavator, river, district locator (with both Historical and 50-District context).
  - Traps and chronological ordering sequences.
- **Mains Lens (Structured Answer Blueprints)**:
  - **2-Mark Questions (15–20 words)**: Definition + 2 core factual pillars.
  - **5-Mark Questions (50 words)**: Core concept + 4–5 structured points/bulleted evidence + summary outcome.
  - **10-Mark Questions (100 words)**: Introduction + Multi-dimensional framework (Social, Economic, Political, Geographical) + Critical evaluation / way forward.
