## 1. 60-Second Sandhi Deconstruction Skeleton

```text
[स्वर संधि (5)] ── दीर्घ: सजातीय मिलकर दीर्घ ──> आ, ई, ऊ, ऋ
                  गुण: अ/आ + इ/ई(ए) | अ/आ + उ/ऊ(ओ) | अ/आ + ऋ(अर्)
                  वृद्धि: अ/आ + ए/ऐ(ऐ) | अ/आ + ओ/औ(औ)
                  यण: इ/ई(य्) | उ/ऊ(व्) | ऋ(र्) ──> पूर्व वर्ण आधा!
                  अयादि: ए(अय्) | ऐ(आय्) | ओ(अव्) | औ(आव्)

[व्यंजन संधि] ──── 1 का 3 = क्, च्, ट्, त्, प् + घोष ──> ग्, ज्, ड्, द्, ब् (दिग्गज, जगदीश)
                  1 का 5 = क्, ट्, त्, प् + नासिक्य ──> ङ्, ण्, न्, म् (वाङ्मय, जगन्नाथ)
                  त्-नियम = त्+च(च्च), त्+ज(ज्ज), त्+ल(ल्ल), त्+श(च्छ), त्+ह(द्ध)
                  तुक्-आगम = ह्रस्व स्वर + छ ──> च्छ (परिच्छेद, तरुच्छाया)
                  णत्व = ऋ/र्/ष् + न ──> ण (परिणाम, रामायण)
                  मूर्धन्यीकरण = भिन्न स्वर + स् ──> ष् (विषम, अभिषेक)

[विसर्ग संधि] ──── उत्व: अ + ः + घोष ──> ओ (मनोयोग, वयोवृद्ध) [अपवाद: पुनः, मुहुः ──> र्]
                  रुत्व: भिन्न स्वर + ः + घोष ──> र् (निर्धन, आयुर्वेद)
                  शत्व/षत्व/सत्व: ः+च/छ(श्) | ः+क/ट/प(ष्) | ः+त/थ(स्)
                  लोप+दीर्घ: ह्रस्व + ः + र ──> दीर्घ + र (नीरोग, नीरस, नीरव)
                  अविकारी: अ + ः + क/ख/प/फ ──> यथावत् (प्रातःकाल, मनःकामना, अंतःकरण)
```

## 2. Master Comparative Distinction Matrices

### Matrix 1: यण संधि बनाम अयादि संधि बनाम गुण संधि

<div style="overflow-x: auto;">

| मापदंड / Parameter | गुण संधि (Guna) | यण संधि (Yana) | अयादि संधि (Ayadi) |
| :--- | :--- | :--- | :--- |
| **प्रथम पद का अंत** | **अ / आ** | **इ/ई, उ/ऊ, ऋ** | **ए, ऐ, ओ, औ** |
| **द्वितीय पद का आरंभ**| इ/ई, उ/ऊ, ऋ | कोई भी **असमान स्वर** | कोई भी **अन्य स्वर** |
| **उत्पन्न विकार** | **ए, ओ, अर्** | **य्, व्, र्** | **अय्, आय्, अव्, आव्** |
| **पहचान की कुंजी** | शिरोरेखा पर 1 मात्रा (`े, ो`) | `य, व, र` से पूर्व **आधा वर्ण** | 3 अक्षरों का सरल शब्द (`नयन, पावक`) |
| **मॉडल उदाहरण** | `सूर्य + उदय = सूर्योदय` | `सु + आगत = स्वागत` | `पौ + अक = पावक` |

</div>

### Matrix 2: विसर्ग संधि के 'ओ' एवं 'र्' विकार का द्वंद्व

<div style="overflow-x: auto;">

| स्थिति | विसर्ग का 'ओ' होना (*उत्व*) | विसर्ग का 'र्' होना (*रुत्व*) |
| :--- | :--- | :--- |
| **पूर्व स्वर** | केवल **'अ'** होना चाहिए (`अ + ः`)। | `अ/आ` को छोड़कर **अन्य कोई स्वर** (`इ, उ + ः`)। |
| **परवर्ती वर्ण** | वर्ग 3, 4, 5 अथवा `य, र, ल, व, ह`। | कोई भी स्वर अथवा वर्ग 3, 4, 5 अथवा `य, र, ल, व, ह`। |
| **उदाहरण** | `यशः + दा = यशोदा`<br/>`मनः + योग = मनोयोग` | `निः + धन = निर्धन`<br/>`दुः + आत्मा = दुरात्मा` |
| **विशिष्ट अपवाद** | — | `पुनः + जन्म = पुनर्जन्म`<br/>`पुनः + अवलोकन = पुनरवलोकन` |

## 3. Top 15 Deadliest Sandhi Traps in RPSC RAS

1. **स्वागत**: `स्व + आगत` (अशुद्ध) $\rightarrow$ **`सु + आगत`** (शुद्ध, यण संधि)।
2. **उज्ज्वल**: `उज + वल` (अशुद्ध) $\rightarrow$ **`उत् + ज्वल`** (शुद्ध व्यंजन संधि, दो आधे 'ज्')।
3. **अभयारण्य**: `अभ्या + रण्य` (अशुद्ध) $\rightarrow$ **`अभय + अरण्य`** (दीर्घ स्वर संधि)।
4. **मनःकामना**: 'मनोकामना' व्याकरणिक दृष्टि से अशुद्ध है $\rightarrow$ शुद्ध रूप **`मनःकामना`** है (अविकारी विसर्ग)।
5. **अधःपतन**: 'अधोपतन' अशुद्ध है $\rightarrow$ शुद्ध रूप **`अधःपतन`** है।
6. **नीरोग**: `नि + रोग` (अशुद्ध) $\rightarrow$ **`निः + रोग`** (विसर्ग लोप से पूर्व 'इ' का 'ई' होना)।
7. **पुनरवलोकन**: 'पुनरावलोकन' अशुद्ध वर्तनी है $\rightarrow$ **`पुनः + अवलोकन = पुनरवलोकन`** (रेफ में 'अ' जुड़ा, 'आ' नहीं)।
8. **अक्षौहिणी**: `अक्ष + ऊहिनी` में गुण के स्थान पर **वृद्धि रूप 'औ'** बनता है (पाणिनीय अपवाद)।
9. **प्रौढ़**: `प्र + ऊढ़` = **प्रौढ़** (गुण का अपवाद, वृद्धि रूप)।
10. **सच्छास्त्र**: `सत् + शास्त्र` में दोहरा विकार: त् $\rightarrow$ च्, श् $\rightarrow$ छ्।
11. **उद्धार**: `उत् + हार` में दोहरा विकार: त् $\rightarrow$ द्, ह् $\rightarrow$ ध्।
12. **मृण्मय**: `मृद् + मय` (अशुद्ध) $\rightarrow$ **`मृत् + मय`** (शुद्ध, प्रथम वर्ण 'त्' का पंचम 'ण्' होना)।
13. **वाङ्मय**: `वाक् + मय` (क् का पंचम 'ङ्' होना, 'वांग्मय' अशुद्ध)।
14. **शूर्पणखा**: `शूर्प + नखा` (णत्व विधान से न् का 'ण्' होना)।
15. **रामायण**: `राम + अयन` (दीर्घ स्वर संधि + णत्व विधान दोनों एक साथ)।
