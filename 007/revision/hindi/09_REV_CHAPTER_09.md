# Chapter 09: शब्द शुद्धि महा-संहिता — Rapid Revision & Diagnostic Vault

## 1. 60-Second Memory Skeleton (Instant Recall)

1. **संधि-जनित नियम**:
   - `अ + अ = आ` $\rightarrow$ अभय + अरण्य = **अभयारण्य** (अभ्यारण्य ❌).
   - `उद् + ज्वल` = **उज्ज्वल** (दो आधे 'ज'; उज्जवल ❌, प्रज्ज्वल ❌ $\rightarrow$ प्र + ज्वल = **प्रज्वल**).
   - `पुनर् + अवलोकन` = **पुनरवलोकन** (पुनरावलोकन ❌).
   - `दुः + अवस्था` = **दुरवस्था** (दुरावस्था ❌).
   - `गति + अवरोध` = **गत्यवरोध** (गत्यावरोध ❌).
   - `अहन् + निश` = **अहर्निश** (अहर्निशि ❌). अहन् + रूप = **अहोरूप**। अहन् + मुख = **अहोमुख**।

2. **प्रत्यय-जनित द्वंद्व (य vs ता महा-दोष)**:
   - 'य' और 'ता' कभी एक साथ नहीं आते!
   - सुंदर $\rightarrow$ **सौंदर्य** अथवा **सुंदरता** (सौंदर्यता ❌).
   - एक $\rightarrow$ **ऐक्य** अथवा **एकता** (ऐक्यता ❌).
   - मधुर $\rightarrow$ **माधुर्य** अथवा **मधुरता** (माधुर्यता ❌).
   - धैर्य $\rightarrow$ **धैर्य** अथवा **धीरता** (धैर्यता ❌).
   - सदृश $\rightarrow$ **सादृश्य** अथवा **सदृशता** (सादृश्यता ❌).
   - पूज्य / माननीय $\rightarrow$ **पूज्य** अथवा **पूजनीय** (पूज्यनीय ❌); **मान्य** अथवा **माननीय** (मान्यनीय ❌).

3. **'इन्' प्रत्ययी दीर्घी vs ह्रस्व रूपान्तरण**:
   - जब 'इन्' प्रत्यय वाले दीर्घ 'ई' अंत वाले शब्दों में 'गण/जन/मंडल/परिषद' जुड़े, तो दीर्घ 'ई' ह्रस्व 'इ' बनती है:
     - प्राणी + विज्ञान = **प्राणिविज्ञान** (प्राणीविज्ञान ❌).
     - मंत्री + मंडल = **मंत्रिमंडल** (मंत्रीमंडल ❌).
     - पक्षी + राज = **पक्षिराज** (पक्षीराज ❌).
     - स्वामी + भक्त = **स्वामिभक्त** (स्वामीभक्त ❌).
     - विद्यार्थी + गण = **विद्यार्थिगण** (विद्यार्थीगण ❌).

4. **इक्की (इक) वृद्धि नियम**:
   - शब्द में 'इक' जुड़ते ही प्रथम स्वर में आदि-वृद्धि होती है:
     - व्यवहार + इक = **व्यावहारिक** (व्यवहारिक ❌).
     - समाज + इक = **सामाजिक** (समाजिक ❌).
     - उद्योग + इक = **औद्योगिक** (ओद्योगिक ❌).
     - अध्यात्म + इक = **आध्यात्मिक** (अध्यात्मिक ❌).
     - प्रमाण + इक = **प्रामाणिक** (प्रमाणिक ❌).
     - सप्ताह + इक = **साप्ताहिक** (सप्ताहिक ❌).
     - अनुषंग + इक = **आनुषंगिक** (अनुषंगिक ❌).

5. **इ/ई एवं उ/ऊ की शुद्ध मात्राएँ**:
   - **कवयित्री** (कवियत्री ❌, कवियित्री ❌).
   - **रचयिता** (रचियता ❌).
   - **उषा** (ऊषा ❌).
   - **नूपुर** (नुपूर ❌, नुपूर ❌).
   - **शूर्पणखा** (सूर्पनखा ❌).
   - **अहल्या** (अहिल्या ❌).
   - **कैकेयी** (कैकई ❌).
   - **अनुगृहीत** (अनुग्रहीत ❌).

## 3. High-Yield Flashcard Drill (20 Rapid Testing Items)

| प्रश्न (अशुद्ध शब्द दिया गया है) | शुद्ध रूप क्या होगा? | त्वरित तर्क / पहचान बिंदु |
| :--- | :--- | :--- |
| 1. प्रदर्शनी vs प्रियदर्शिनी | **प्रदर्शनी**, **प्रियदर्शिनी** | प्रदर्शन में ई = प्रदर्शनी ('शि' नहीं); प्रियदर्शिन में ई = प्रियदर्शिनी। |
| 2. अंताक्षरी | **अंत्याक्षरी** | अंत्य (अंतिम) + अक्षरी = अंत्याक्षरी। |
| 3. अहर्निशि | **अहर्निश** | अहन् + निशा = समासांत में 'अहर्निश' बनता है। |
| 4. संग्रहित | **संगृहीत** | सम् + ग्रह् + क्त = संगृहीत (ऋकार + दीर्घ ई)। |
| 5. दृष्टव्य | **द्रष्टव्य** | दृश् धातु में तव्यत् जुड़ने पर 'द्र' बनता है ('दृ' नहीं)। |
| 6. स्रष्टा vs सृष्टि | **स्रष्टा**, **सृष्टि** | 'ता' जुड़ने पर स्रष्टा ('स्र'); 'ति' जुड़ने पर सृष्टि ('सृ')। |
| 7. जागृत vs जाग्रत | **जाग्रत** / **जागृति** | जाग्रत अवस्था; जागृति (भाववाचक संज्ञा)। |
| 8. पैतृक | **पैतृक** | पितृ + इक = पैतृक (ऐ की मात्रा + ऋकार)। |
| 9. युधिष्ठर | **युधिष्ठिर** | युधि + स्थिर = युधिष्ठिर ('ठि' में ह्रस्व इ)। |
| 10. महात्म्य | **माहात्म्य** | महात्मा + य = माहात्म्य (आदि-वृद्धि + अंत्य अ लोप)। |
| 11. चारुताई | **चारुता** / **चारुत्व** | चारु में 'ता' या 'त्व' जुड़ेगा; 'ताई' अशुद्ध है। |
| 12. निरोग | **नीरोग** | निः + रोग = नीरोग (विसर्ग लोप से पूर्व स्वर दीर्घ)। |
| 13. चक्षुरोग | **चक्षूरोग** | चक्षुस् + रोग = चक्षूरोग ('क्षू' दीर्घ)। |
| 14. तदुपरांत | **तदुपरांत** | तत् + उपरांत = तदुपरांत (तदोपरांत ❌ अशुद्ध)। |
| 15. उत्तरोत्तर | **उत्तरोत्तर** | उत्तर + उत्तर = उत्तरोत्तर (गुण संधि)। |
| 16. पुनरुत्थान | **पुनरुत्थान** | पुनर् + उत्थान = पुनरुत्थान (पुनरोत्थान ❌)। |
| 17. उपरोक्‍त | **उपर्युक्त** | उपरि + उक्त = उपर्युक्त (यण संधि)। |
| 18. अंतर्ध्यान | **अंतर्धान** | अन्तर् + धा + ल्युट् = अंतर्धान ('ध्यान' नहीं)। |
| 19. वांग्मय | **वाङ्मय** | वाक् + मय = वाङ्मय (क-वर्ग का पंचमाक्षर ङ्)। |
| 20. षोडशी | **षोडशी** | षष् + दश = षोडशी (सोलह वर्ष की कन्या)। |
