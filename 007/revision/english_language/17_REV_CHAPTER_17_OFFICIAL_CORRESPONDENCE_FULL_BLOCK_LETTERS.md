## 1. Core Distinction Matrices

### Matrix A: Formal vs. Informal Full-Block Mechanics

| Structural Element | Formal Letter (Bank Manager, Editor, Regulator) | Informal Letter (Sibling, Parent, Close Friend) |
| :--- | :--- | :--- |
| **Sender's Address** | Mandated (Flush Left, 2–3 lines, no personal name). | Mandated (Flush Left, 2–3 lines). |
| **Date Line** | Full formal format: *October 14, 2026*. | Full formal format: *October 14, 2026*. |
| **Recipient's Address**| Mandated (Designation + Organization + City). | **OMITTED COMPLETELY**. |
| **Subject Line** | Mandated (6–10 words, bold/underlined). | **OMITTED COMPLETELY**. |
| **Salutation** | *Sir / Madam* or *Dear Sir / Madam*. | *Dear Raghav / Dearest Mother*. |
| **Tone & Register** | Objective, detached, forensic, statutory. | Warm, advisory, conversational, personal. |
| **Body Layout** | Strict 3 paragraphs: Context ➔ Facts ➔ Remedy. | Fluid narrative (3 paragraphs: Opening ➔ Advice ➔ Closing). |
| **Complimentary Close** | *Yours faithfully* (or *Yours sincerely* if named). | *Yours affectionately / With warm regards*. |

### Matrix B: Punctuation & Grammatical Invariants

| Element | Approved Standard | Fatal Penalized Cliché / Error |
| :--- | :--- | :--- |
| **Date** | *October 14, 2026* | *14/10/26* ❌ or *14th Oct 2026* ❌ |
| **Salutation** | *Sir / Madam* | *Respected Sir* ❌ (Archaic & ungrammatical). |
| **Possessive Pronoun**| *Yours* (No apostrophe) | *Your's* ❌ (Severe grammatical error). |
| **Adverbial Casing** | *Yours faithfully* (lowercase 'f') | *Yours Faithfully* ❌ (Incorrect capitalization). |
| **Paragraph Break** | Single blank line (Double Enter) | Tab indents ❌ (Violates modern block rules). |

## 2. 60-Second Retrieval Skeleton

```text
Full-Block Standard: 100% Left Margin Aligned (0 Tab Indents, 0 Right-alignments) 
➔ Date: October 14, 2026 (No slashes, no 'th') 
➔ Subject: Concise (6-10 words, highlighted, between address and salutation) 
➔ Formal Salutation: Sir / Madam ➔ Close: Yours faithfully (Yours has NO apostrophe, lowercase f) 
➔ If recipient is named (Dear Mr. Sen): Close with Yours sincerely 
➔ Informal: Omit recipient address & subject line ➔ Dear [Name] ➔ Yours affectionately 
➔ Tri-Paragraph Formal Body: Para 1 (Purpose & A/C ID) ➔ Para 2 (Facts & Breach) ➔ Para 3 (Action & Deadline).
```

## 3. High-Yield Examination Flashcards

#### Card 1
* **Diagnostic Sentence**: *Why is writing "Respected Sir" penalized in RBI Grade B and Bank PO letter writing?*
* **Answer**: In professional modern English correspondence, *respected* is considered an archaic colonial tautology. The standard, dignified formal salutations are *Sir*, *Madam*, or *Dear Sir / Madam*.

#### Card 2
* **Diagnostic Question**: *In a complaint letter to a bank manager regarding an unauthorized debit, what two specific details must appear in the first paragraph?*
* **Answer**: The specific **Bank Account Number** and the **exact nature/date of the grievance or unauthorized transaction**.

#### Card 3
* **Diagnostic Question**: *What is the penalty for writing "Thanking you" before "Yours faithfully"?*
* **Answer**: *"Thanking you"* is a grammatically incomplete hanging participial phrase. Examiners flag it as outdated writing; the letter should transition directly from the final body paragraph to the complimentary close.
