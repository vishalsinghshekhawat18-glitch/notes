## Operating Principles for Shelf 007

1. **Isolation Guarantee**: All operations, files, edits, and synthesis occur exclusively inside this `007/` tree. Nothing outside this folder is touched.
2. **PhD-Level Depth & First Principles**: Unpack the causal mechanics, mathematical/institutional intuitions, assumptions, and constitutional architectures behind every concept.
3. **The Golden Rule of Total Replacement**: Distilled notes must be so complete and authoritative that you never need to reopen the original book, PDF, or video.
4. **Radical Non-Duplication**: Multiple sources covering the same topic are consolidated into a single immutable canonical note. New sources only deepen, clarify, or cite evidence.
5. **One Canonical Base, Multi-Exam Lenses**: The core constitutional or economic mechanism exists once; specific exam requirements (UPSC CSE, RPSC RAS, Banking, UGC-NET) are layered on top as analytical lenses.
6. **Built-in Active Recall**: Every note includes high-retrieval flashcards, trap alerts, and distinction matrices.
7. **Zero Unaccounted-For Omission**: Every source ingested is fully accounted for in the master index and curriculum ledger.
8. **Deployment Governance**: Push to remote git ONLY upon explicit user instruction.
