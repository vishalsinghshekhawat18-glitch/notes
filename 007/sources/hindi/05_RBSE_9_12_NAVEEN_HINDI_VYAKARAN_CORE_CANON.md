## 1. वर्ण विचार एवं उच्चारण स्थान (Phonetic Classification)

* **मूल स्वर (ह्रस्व स्वर)**: अ, इ, उ, ऋ (4 स्वर — एक मात्रिक)
* **दीर्घ स्वर**: आ, ई, ऊ, ए, ऐ, ओ, औ (7 स्वर — द्विमात्रिक)
  - *सजातीय दीर्घ*: अ+अ=आ, इ+इ=ई, उ+उ=ऊ
  - *संयुक्त स्वर*: अ+इ=ए, अ+ए=ऐ, अ+उ=ओ, अ+ओ=औ
* **जीभ की क्रियाशीलता के आधार पर**:
  - अग्र स्वर: इ, ई, ए, ऐ
  - मध्य स्वर: अ
  - पश्च स्वर: आ, उ, ऊ, ओ, औ
* **मुख विवर (खुलने) के आधार पर**:
  - संवृत (Closed): इ, ई, उ, ऊ
  - अर्ध-संवृत: ए, ओ
  - विवृत (Open): आ
  - अर्ध-विवृत: अ, ऐ, औ

## 2. संधि विधान: RBSE मानक नियम

### स्वर संधि (5 प्रकार):
1. **दीर्घ संधि ($अ/आ + अ/आ = आ$, $इ/ई + इ/ई = ई$, $उ/ऊ + उ/ऊ = ऊ$)**:
   - `परम + अणु` = परमाणु, `कपि + ईश` = कपीश, `भानु + उदय` = भानूदय
2. **गुण संधि ($अ/आ + इ/ई = ए$, $अ/आ + उ/ऊ = ओ$, $अ/आ + ऋ = अर्$)**:
   - `नर + ईश` = नरेश, `महा + उत्सव` = महोत्सव, `सप्त + ऋषि` = सप्तर्षि
3. **वृद्धि संधि ($अ/आ + ए/ऐ = ऐ$, $अ/आ + ओ/औ = औ$)**:
   - `एक + एक` = एकैक, `महा + ऐश्वर्य` = महैश्वर्य, `जल + ओघ` = जलौघ, `परम + औदार्य` = परमौदार्य
4. **यण संधि ($इ/ई + असमान = य्$, $उ/ऊ + असमान = व्$, $ऋ + असमान = र्$)**:
   - `यदि + अपि` = यद्यपि, `इति + आदि` = इत्यादि, `सु + आगत` = स्वागत, `अनु + एषण` = अन्वेषण, `पितृ + आज्ञा` = पित्राज्ञा
5. **अयादि संधि ($ए/ऐ/ओ/औ + असमान = अय्/आय्/अव्/आव्$)**:
   - `ने + अन` = नयन, `नै + अक` = नायक, `पो + अन` = पवन, `पौ + अक` = पावक

### व्यंजन संधि के मुख्य सूत्र:
* **प्रथम वर्ण का तृतीय वर्ण में परिवर्तन ($क, च, ट, त, प + घोष = ग, ज, ड, द, ब$)**:
  - `दिक् + गज` = दिग्गज, `अच् + अंत` = अजंत, `षट् + आनन` = षडानन, `जगत् + ईश` = जगदीश, `अप् + द` = अब्द
* **प्रथम वर्ण का पंचम वर्ण में परिवर्तन ($क, च, ट, त, प + नासिक्य = ङ, ञ, ण, न, म$)**:
  - `वाक् + मय` = वाङ्मय, `षट् + मास` = षण्मास, `जगत् + नाथ` = जगन्नाथ, `उत् + नति` = उन्नति
* **'त्' संबंधी विशिष्ट नियम**:
  - `त् + च/छ = च्च/च्छ`: `उत् + चारण` = उच्चारण, `सत् + चरित्र` = सच्चरित्र
  - `त् + ज/झ = ज्ज`: `उत् + ज्वल` = उज्ज्वल, `सत् + जन` = सज्जन
  - `त् + ल = ल्ल`: `उत् + लास` = उल्लास, `तत् + लीन` = तल्लीन
  - `त् + श = च्छ`: `उत् + श्वास` = उच्छ्वास, `सत् + शास्त्र` = सच्छास्त्र
  - `त् + ह = द्ध`: `उत् + हार` = उद्धार, `तत् + हित` = तद्धित

### विसर्ग संधि के मुख्य सूत्र:
* **विसर्ग का 'ओ' होना ($अ + ः + घोष = ओ$)**:
  - `मनः + अनुकूल` = मनोनुकूल, `तपः + बल` = तपोबल, `वयः + वृद्ध` = वयोवृद्ध, `यशः + दा` = यशोदा
  - *अपवाद*: `पुनः` एवं `मुहुः` में विसर्ग का 'र्' बनता है: `पुनः + जन्म` = पुनर्जन्म, `पुनः + अवलोकन` = पुनरवलोकन
* **विसर्ग का 'र्' होना ($अ/आ से भिन्न स्वर + ः + घोष = र्$)**:
  - `निः + धन` = निर्धन, `दुः + बल` = दुर्बल, `निः + आशा` = निराशा, `आशीः + वाद` = आशीर्वाद
* **विसर्ग का 'श्', 'ष्', 'स्' होना**:
  - `निः + चय` = निश्चय, `हरिः + चन्द्र` = हरिश्चन्द्र
  - `धनुः + टंकार` = धनुष्टंकार, `निः + फल` = निष्फल, `निः + कपट` = निष्कपट
  - `नमः + ते` = नमस्ते, `दुः + साहस` = दुस्साहस
* **विसर्ग लोप एवं पूर्व स्वर दीर्घ होना ($ः + र = पूर्व दीर्घ$)**:
  - `निः + रोग` = **नीरोग**, `निः + रस` = **नीरस**, `निः + रव` = **नीरव**

## 3. RBSE मानक वर्तनी (High Court Benchmarks)

1. **'श्रीमान्' / 'महान्' / 'परिषद्'**: तत्सम शब्दों में अंत्य हलन्त मानक माना जाता है।
2. **'मिष्टान्न'**: `मिष्ट + अन्न` मानक है, 'मिष्ठान्न' अशुद्ध है।
3. **'अभयारण्य'**: `अभय + अरण्य` मानक है, 'अभ्यारण्य' अशुद्ध है।
4. **'कवयित्री'**: शुद्ध रूप 'कवयित्री' है।
5. **'अहल्या'**: शुद्ध रूप 'अहल्या' है, 'अहिल्या' अशुद्ध है।
6. **'द्वारका'**: शुद्ध रूप 'द्वारका' है, 'द्वारिका' अशुद्ध है।
7. **'वाङ्मय'**: शुद्ध रूप 'वाङ्मय' है।
