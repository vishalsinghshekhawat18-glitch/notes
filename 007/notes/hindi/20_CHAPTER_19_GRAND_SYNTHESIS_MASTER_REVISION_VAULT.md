## 2. 30-Minute Pre-Exam Sprint Vault (परीक्षा-कक्ष में प्रवेश से पूर्व अंतिम 30 मिनट)

### भाग 1: संधि महा-सूत्र (The Sandhi Engine in 10 Formulas)
1. **दीर्घ**: $a/ā + a/ā = ā$; $i/ī + i/ī = ī$; $u/ū + u/ū = ū$ (अभय + अरण्य = **अभयारण्य**; श्री + ईश = **श्रीमती**; सु + उक्ति = **सूक्ति**)।
2. **गुण**: $a/ā + i/ī = e$; $a/ā + u/ū = o$; $a/ā + \text{ऋ} = ar$ (महा + ईश = **महेश**; सूर्य + उदय = **सूर्योदय**; महा + ऋषि = **महर्षि**)।
3. **वृद्धि**: $a/ā + e/ai = ai$; $a/ā + o/au = au$ (एक + एक = **एकैक**; मत + ऐक्य = **मतैक्य**; महा + ओजस्वी = **महौजस्वी**; महा + औषध = **महौषध**)।
4. **यण**: $i/ī \rightarrow y$; $u/ū \rightarrow v$; $\text{ऋ} \rightarrow r$ (यदि + अपि = **यद्यपि**; अनु + अय = **अन्वय**; पितृ + आज्ञा = **पित्राज्ञा**)।
5. **अयादि**: $e \rightarrow ay$; $ai \rightarrow āy$; $o \rightarrow av$; $au \rightarrow āv$ (ने + अन = **नयन**; गै + अक = **गायक**; पो + अन = **पवन**; पौ + अक = **पावक**)।
6. **व्यंजन 'त्' नियम**: त् + च/छ = च्च (**सच्चरित्र**); त् + ज/झ = ज्ज (**उज्ज्वल**, **सज्जन**); त् + ल = ल्ल (**उल्लेख**); त् + श = च्छ (**उच्छ्वास**); त् + ह = द्ध (**उद्धार**)।
7. **व्यंजन प्रथम से पंचम**: क्/च्/ट्/त्/प् + अनुनासिक $\rightarrow$ पंचमाक्षर (वाक् + मय = **वाङ्मय**; उत् + नति = **उन्नति**; जगत् + नाथ = **जगन्नाथ**)।
8. **विसर्ग 'ओ' नियम**: अ + ः + घोष वर्ण $\rightarrow$ ओ (मनः + हर = **मनोहर**; सरः + वर = **सरोवर**; यशः + दा = **यशोदा**; पयः + धर = **पयोधर**)।
9. **विसर्ग 'र्' नियम**: अ/आ से भिन्न स्वर + ः + घोष वर्ण $\rightarrow$ र् (निः + धन = **निर्धन**; दुः + अवस्था = **दुरवस्था**; निः + उपाय = **निरुपाय**)।
10. **विसर्ग लोप व दीर्घ**: निः + रोग = **नीरोग**; निः + रस = **नीरस**; प्रातः + काल = **प्रातःकाल** (विसर्ग सुरक्षित)।

### भाग 3: वाक्य शुद्धि के 10 स्वर्ण नियम (Sentence Correction Decalogue)
1. 'कृपया' और 'कृपा' एक साथ कभी नहीं $\rightarrow$ "कृपया आप पधारें।"
2. 'काल' और 'समय' एक साथ कभी नहीं $\rightarrow$ "वह प्रातःकाल भ्रमण करता है।"
3. 'दंड' और 'सजा' एक साथ कभी नहीं $\rightarrow$ "उसे मृत्युदंड दिया गया।"
4. 'सारे' और 'भर' एक साथ कभी नहीं $\rightarrow$ "सारे देश में" अथवा "देश भर में"।
5. विशेषण सदा विशेष्य के ठीक पहले $\rightarrow$ "फूलों की एक माला", "गाय का शुद्ध दूध"।
6. 'बोलना, भूलना, लाना, जानना' में 'ने' नहीं आता $\rightarrow$ "वह झूठ बोला", "नौकर पानी लाया"।
7. नित्य बहुवचन शब्द (हस्ताक्षर, आँसू, प्राण, दर्शन, होश) $\rightarrow$ "मैंने हस्ताक्षर कर दिए।"
8. निपात (भी, ही, मात्र, केवल) उस शब्द के ठीक बाद आता है जिस पर बल हो।
9. बंदूक 'शस्त्र' है (हाथ में थामकर चलने वाला); तीर/भाला 'अस्त्र' है (फेंककर चलाने वाला)।
10. 'मेरे को / तेरे को' सर्वथा अशुद्ध $\rightarrow$ 'मुझे / तुझे / आपको'।

```
[अर्ध-शासकीय पत्र]  ऊपर बाईं ओर प्रेषक का नाम/पद -> ऊपर दाहिनी ओर अ.शा.प. क्रमांक व दिनांक -> प्रिय श्री ... जी -> कलेवर (उत्तम पुरुष) -> आपका -> नीचे बाईं ओर प्रेषिती का नाम/पद
[निविदा सूचना]     शीर्ष पर विभाग -> ई-निविदा सूचना संख्या -> 6-कॉलम तालिका (क्र.सं., कार्य, लागत, EMD, शुल्क, अवधि) -> महत्वपूर्ण तिथियाँ -> RTPP Act 2012 -> हस्ताक्षर
[अधिसूचना]          शीर्ष पर विभाग -> अधिसूचना -> सांविधिक संदर्भ (अनुच्छेद 309) -> नियम/आदेश -> "राज्यपाल महोदय के आदेश से" -> प्रतिलिपि राजकीय मुद्रणालय (राजपत्र)
[परिपत्र]            शीर्ष पर विभाग -> परिपत्र -> विषय -> सभी अधीनस्थों को सामान्य निर्देश -> पाक्षिक रिपोर्ट मांग -> हस्ताक्षर -> प्रतिलिपि
[कार्यालय आदेश]      शीर्ष पर विभाग -> कार्यालय आदेश -> कर्मचारियों का कार्य-विभाजन/छुट्टी/तबादला -> तत्काल प्रभाव से -> हस्ताक्षर -> प्रतिलिपि
```

### भाग 6: संक्षिप्तीकरण, पल्लवन, अनुवाद एवं निबंध का त्वरित मंत्र

- **संक्षिप्तीकरण (10 अंक)**: $\frac{1}{3} \pm 10\%$ शब्द | आकर्षक 2-4 शब्दों का शीर्षक | अन्य पुरुष | उदाहरण/अलंकार/कोटेशन पूर्णतः बाहर | अंत में शब्द गणना लिखें।
- **पल्लवन (10 अंक)**: लगभग 100 शब्द | व्यास शैली | त्रि-स्तरीय संरचना (बीज भाव $\rightarrow$ तार्किक विस्तार $\rightarrow$ प्रेरणादायी निष्कर्ष) | शून्य व्यक्तिगत पूर्वाग्रह।
- **अनुवाद (10 अंक)**: S-V-O को S-O-V में बदलें | Prepositional Phrases मध्य/प्रारंभ में लाएं | CSTT तकनीकी शब्दावली अक्षुण्ण रखें | कोई उपवाक्य न छोड़ें।
- **निबंध (20 अंक)**: लगभग 250-300 शब्द | शीर्ष पर 4-5 बिंदुओं की रूपरेखा अनिवार्य | श्लोक/काव्य-पंक्ति से शुरुआत | PESTLE बहु-आयामी विस्तार | राजस्थान परिदृश्य | आशावादी संवैधानिक निष्कर्ष।
