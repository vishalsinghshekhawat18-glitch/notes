## 2.1 संधि की तात्विक अवधारणा (Epistemic Foundation)

### 1. परिभाषा एवं स्वरूप:
दो निकटवर्ती वर्णों के परस्पर मेल से उत्पन्न **ध्वन्यात्मक विकार (परिवर्तन)** को **संधि** कहते हैं:
$$\text{प्रथम शब्द का अंतिम वर्ण} + \text{द्वितीय शब्द का प्रथम वर्ण} \longrightarrow \mathbf{ध्वन्यात्मक \ विकार \ (संधि)}$$

> **[⚖️ संधि बनाम संयोग (Sandhi vs. Conjunction)]**:  
> - **संधि**: जहां वर्णों के मिलने से अनिवार्य रूप से **ध्वनि विकार (परिवर्तन/लोप/आगम)** हो:  
>   `विद्या + आलय = विद्यालय` (आ + आ = आ), `सत् + जन = सज्जन` (त् का ज् होना)।  
> - **संयोग**: जहां दो वर्ण पास-पास आते हैं किन्तु उनके मूल रूप में **कोई ध्वनि विकार नहीं होता**:  
>   `युग + बोध = युगबोध`, `अन + देखा = अनदेखा`, `देश + भक्त = देशभक्त`।  
>   *RPSC Trap*: 'देशभक्त' या 'अनदेखा' में संधि नहीं है, केवल **संयोग** है!

---

### 2. संधि के तीन मूल भेद:
1. **स्वर संधि (अच् संधि)**: स्वर + स्वर का मेल $\rightarrow$ विकार स्वर में।
2. **व्यंजन संधि (हल संधि)**: व्यंजन + स्वर/व्यंजन अथवा स्वर + व्यंजन $\rightarrow$ विकार व्यंजन में।
3. **विसर्ग संधि**: विसर्ग (:) + स्वर/व्यंजन $\rightarrow$ विकार विसर्ग में।

---

## 2.2 स्वर संधि महा-विज्ञान (Vowel Euphonic System — 5 भेद)

दो स्वरों के परस्पर मेल से जो विकार उत्पन्न होता है, उसे **स्वर संधि** कहते हैं। इसके 5 सर्वमान्य भेद हैं:

---

### 1. दीर्घ स्वर संधि (*अकः सवर्णे दीर्घः*)
**नियम**: जब ह्रस्व या दीर्घ `अ, इ, उ, ऋ` के बाद क्रमशः वही समान स्वर (ह्रस्व या दीर्घ `अ, इ, उ, ऋ`) आए, तो दोनों मिलकर **दीर्घ (`आ, ई, ऊ, ॠ`)** बन जाते हैं:

$$अ/आ + अ/आ = \mathbf{आ} \qquad इ/ई + इ/ई = \mathbf{ई} \qquad उ/ऊ + उ/ऊ = \mathbf{ऊ} \qquad ऋ + ऋ = \mathbf{ऋ}$$

#### प्रामाणिक उदाहरण तालिका:
<div style="overflow-x: auto;">

| रूपान्तरण सूत्र | उदाहरण (संधि पद) | संधि-विच्छेद (मूल पद) | विशिष्ट अर्थ / व्याकरणिक टिप्पणी |
| :--- | :--- | :--- | :--- |
| **अ + अ = आ** | **परमाणु** | `परम + अणु` | परम है जो अणु |
| **अ + अ = आ** | **गीतांजलि** | `गीत + अंजलि` | 'अंजलि' में 'लि' ह्रस्व होती है |
| **अ + आ = आ** | **हिमालय** | `हिम + आलय` | बर्फ का घर |
| **आ + अ = आ** | **सीमांत** | `सीमा + अंत` | सीमा का अंतिम छोर |
| **आ + आ = आ** | **महाशय** | `महा + आशय` | महान आशय वाला |
| **इ + इ = ई** | **कवींद्र** | `कवि + इंद्र` | 'इंद्र' में 'इ' ह्रस्व होती है |
| **इ + ई = ई** | **कपीश** | `कपि + ईश` | 'ईश' में 'ई' दीर्घ होती है |
| **ई + इ = ई** | **महींद्र** | `मही + इंद्र` | मही (पृथ्वी) का स्वामी |
| **ई + ई = ई** | **नदीश** | `नदी + ईश` | समुद्र |
| **उ + उ = ऊ** | **भानूदय** | `भानु + उदय` | सूर्योदय ('भानु' में 'नु' ह्रस्व, 'उदय' में 'उ' ह्रस्व) |
| **उ + ऊ = ऊ** | **लघूर्मि** | `लघु + ऊर्मि` | 'ऊर्मि' (लहर) में 'ऊ' दीर्घ होता है |
| **ऊ + उ = ऊ** | **वधूत्सव** | `वधू + उत्सव` | 'वधू' में 'धू' सदैव दीर्घ होता है |
| **ऊ + ऊ = ऊ** | **भूष्मा** | `भू + ऊष्मा` | 'ऊष्मा' में 'ऊ' दीर्घ होता है |
| **ऋ + ऋ = ऋ** | **पितृण** | `पितृ + ऋण` | पिता का ऋण (हिन्दी में एकल 'ऋ' लिखा जाता है) |

</div>

> **[⚡ RPSC TRAP ALERT: दीर्घ संधि के घातक जाल]**:  
> 1. `वधू + आगमन` = **वध्वागमन** (यह यण संधि है, दीर्घ नहीं!). दीर्घ संधि केवल तभी होगी जब आगे 'उ/ऊ' हो: `वधू + उत्सव = वधूत्सव`।  
> 2. `कवि + ईश` = **कपीश** (हनुमान/सुग्रीव) vs `कपि + ईश्वर` = **कपीश्वर**।  
> 3. `अभयारण्य` = `अभय + अरण्य` (अ+अ=आ). 'अभ्यारण्य' लिखना अशुद्ध है!

---

### 2. गुण स्वर संधि (*आद्गुणः*)
**नियम**: यदि `अ` या `आ` के बाद `इ/ई`, `उ/ऊ` अथवा `ऋ` आए, तो दोनों मिलकर क्रमशः **`ए`**, **`ओ`** और **`अर्`** बन जाते हैं:

$$अ/आ + इ/ई = \mathbf{ए} \qquad अ/आ + उ/ऊ = \mathbf{ओ} \qquad अ/आ + ऋ = \mathbf{अर्}$$

#### प्रामाणिक उदाहरण तालिका:
<div style="overflow-x: auto;">

| रूपान्तरण | संधि पद | संधि-विच्छेद | परीक्षा बिंदु / टिप्पणी |
| :--- | :--- | :--- | :--- |
| **अ + इ = ए** | **भारतेंदु** | `भारत + इंदु` | इंदु = चंद्रमा (ह्रस्व इ) |
| **अ + ई = ए** | **परमेश्वर** | `परम + ईश्वर` | ईश्वर (दीर्घ ई) |
| **आ + ई = ए** | **गुड़ाकेश** | `गुड़ाका + ईश` | गुड़ाका = निद्रा (अर्जुन/शिव) |
| **आ + ई = ए** | **राकेश** | `राका + ईश` | राका = पूर्णिमा की रात्रि (चंद्रमा) |
| **अ + उ = ओ** | **सूर्योदय** | `सूर्य + उदय` | सामान्य गुण संधि |
| **अ + ऊ = ओ** | **जलोर्मि** | `जल + ऊर्मि` | ऊर्मि = तरंग (दीर्घ ऊ) |
| **आ + ऊ = ओ** | **महोर्जा** | `महा + ऊर्जा` | ऊर्जा = शक्ति (दीर्घ ऊ) |
| **अ + ऋ = अर्**| **सप्तर्षि** | `सप्त + ऋषि` | `सप्त + अर् + षि` = सप्तर्षि |
| **आ + ऋ = अर्**| **महर्षि** | `महा + ऋषि` | `मह् + अर् + षि` = महर्षि |
| **आ + ऋ = अर्**| **वर्षातु** | `वर्षा + ऋतु` | `वर्ष + अर् + तु` = वर्षर्तु |

</div>

> **[⚖️ गुण संधि के शास्त्रीय अपवाद (Direct Exam Traps)]**:  
> 1. `अक्ष + ऊहिनी` = **अक्षौहिणी** (नियम से 'ओ' होना चाहिए था, किन्तु 'औ' वृद्धि रूप बनता है — पाणिनीय वार्तिक: *अक्षादूहिन्यामुपसंख्यानम्*)।  
> 2. `प्र + ऊढ़` = **प्रौढ़** (नियम से 'ओ' होना चाहिए, किन्तु 'औ' बनता है)।  
> 3. `सुख + ऋत` = **सुखार्त** (`सुख + अर् + त` नहीं, बल्कि 'आर्' वृद्धि रूप बनता है — तृतीया तत्पुरुष समास में)।

---

### 3. वृद्धि स्वर संधि (*वृद्धिरेचि*)
**नियम**: यदि `अ` या `आ` के बाद `ए` या `ऐ` आए तो दोनों मिलकर **`ऐ`** बन जाते हैं, और यदि `ओ` या `औ` आए तो दोनों मिलकर **`औ`** बन जाते हैं:

$$अ/आ + ए/ऐ = \mathbf{ऐ} \qquad अ/आ + ओ/औ = \mathbf{औ}$$

#### प्रामाणिक उदाहरण तालिका:
<div style="overflow-x: auto;">

| रूपान्तरण | संधि पद | संधि-विच्छेद | परीक्षा बिंदु / टिप्पणी |
| :--- | :--- | :--- | :--- |
| **अ + ए = ऐ** | **एकैक** | `एक + एक` | एक-एक करके |
| **अ + ऐ = ऐ** | **मतैक्य** | `मत + ऐक्य` | ऐक्य में 'ऐ' होता है |
| **आ + ऐ = ऐ** | **महैश्वर्य** | `महा + ऐश्वर्य` | ऐश्वर्य में 'ऐ' होता है |
| **अ + ए = ऐ** | **हितैषी** | `हित + एषी` | 'एषी' (चाहने वाला) में 'ए' ह्रस्व |
| **आ + ए = ऐ** | **तथैव** | `तथा + एव` | 'एव' में 'ए' ह्रस्व |
| **अ + ओ = औ** | **जलोघ** | `जल + ओघ` | ओघ = प्रवाह (ह्रस्व ओ) |
| **अ + औ = औ** | **परमौषध** | `परम + औषध` | औषध में 'औ' होता है |
| **आ + औ = औ** | **महौदार्य** | `महा + औदार्य` | औदार्य = उदारता |

</div>

> **[⚖️ वृद्धि संधि के विशिष्ट अपवाद]**:  
> - `दन्त + ओष्ठ` = **दन्तोष्ठ** अथवा **दन्तौष्ठ** (दोनों मान्य; नियमतः 'औ' होना चाहिए किन्तु गुण 'ओ' भी स्वीकार्य)।  
> - `बिम्ब + ओष्ठ` = **बिम्बोष्ठ** अथवा **बिम्बौष्ठ**।  
> - `शुद्ध + ओदन` = **शुद्धोदन** (बुद्ध के पिता; 'औ' के स्थान पर 'ओ' का प्रवृत्त होना)।

---

### 4. यण स्वर संधि (*इको यणचि*)
**नियम**: यदि ह्रस्व या दीर्घ `इ/ई`, `उ/ऊ` अथवा `ऋ` के बाद कोई **असमान (विजातीय) स्वर** आए, तो:
1. `इ / ई` का **`य्`** हो जाता है।
2. `उ / ऊ` का **`व्`** हो जाता है।
3. `ऋ` का **`र्`** हो जाता है।
*(और बाद वाला स्वर य्, व्, र् की मात्रा बनकर जुड़ जाता है!)*

#### यण संधि की पहचान:
संधि पद में `य, व, र` से ठीक पहले **आधा (स्वर-रहित) व्यंजन** अवश्य विद्यमान रहता है!

#### प्रामाणिक उदाहरण तालिका:
<div style="overflow-x: auto;">

| मूल स्वर | संधि पद | संधि-विच्छेद | आंतरिक प्रक्रिया |
| :--- | :--- | :--- | :--- |
| **इ + अ = य** | **यद्यपि** | `यदि + अपि` | `यद् + य् + अपि` = यद्यपि |
| **इ + आ = या** | **इत्यादि** | `इति + आदि` | `इत् + य् + आदि` = इत्यादि |
| **इ + उ = यु** | **अत्युत्तम** | `अति + उत्तम` | `अत् + य् + उत्तम` = अत्युत्तम |
| **इ + ऊ = यू** | **व्यूह** | `वि + ऊह` | `व् + य् + ऊह` = व्यूह |
| **ई + आ = या** | **नद्यामुख** | `नदी + आमुख` | `नद् + य् + आमुख` = नद्यामुख |
| **ई + अ = य** | **नद्यर्पण** | `नदी + अर्पण` | `नद् + य् + अर्पण` = नद्यर्पण |
| **ई + ऐ = यै** | **सख्यैश्वर्य**| `सखी + ऐश्वर्य`| `सख् + य् + ऐश्वर्य` |
| **उ + अ = व** | **अन्वय** | `अनु + अय` | `अन् + व् + अय` = अन्वय |
| **उ + आ = वा** | **स्वागत** | `सु + आगत` | `स् + व् + आगत` = स्वागत |
| **उ + इ = वि** | **अन्वित** | `अनु + इत` | `अन् + व् + इत` = अन्वित (RAS 2023) |
| **उ + ए = वे** | **अन्वेषण** | `अनु + एषण` | `अन् + व् + एषण` = अन्वेषण (RAS 2021)|
| **ऊ + आ = वा** | **वध्वागमन** | `वधू + आगमन` | `वध् + व् + आगमन` = वध्वागमन |
| **ऋ + अ = र** | **पितरनुमति**| `पितृ + अनुमति`| `पित् + र् + अनुमति` = पित्रनुमति |
| **ऋ + आ = रा** | **पित्राज्ञा** | `पितृ + आज्ञा` | `पित् + र् + आज्ञा` = पित्राज्ञा |
| **ऋ + उ = रु** | **मात्रुपदेश**| `मातृ + उपदेश`| `मात् + र् + उपदेश` = मात्रुपदेश (RAS 2021)|

</div>

> **[⚡ RPSC TRAP ALERT: 'स्वागत' एवं 'अन्वेषण']**:  
> - `स्वागत` का विच्छेद `स्व + आगत` कभी न करें! `स्व + आगत` का अर्थ होगा 'स्वयं का आगमन'। सही विच्छेद है **`सु + आगत`** (सु = सुंदर/शुभ, आगत = आना)।  
> - `पित्रनुमति` में 'त्रा' नहीं होता, केवल 'त्र' होता है (`पितृ + अनुमति = पित्रनुमति`, पित्राजा की भांति 'पित्रा' नहीं!)।

### 5. अयादि स्वर संधि (*एचोऽयवायावः*)
**नियम**: यदि `ए, ऐ, ओ, औ` के बाद कोई भी अन्य स्वर आए, तो क्रमशः:
- **`ए`** का **`अय्`**
- **`ऐ`** का **`आय्`**
- **`ओ`** का **`अव्`**
- **`औ`** का **`आव्`**
हो जाता है (और बाद वाला स्वर इनमें मात्रा के रूप में जुड़ जाता है)।

#### प्रामाणिक उदाहरण तालिका:
<div style="overflow-x: auto;">

| रूपान्तरण | संधि पद | संधि-विच्छेद | ध्वन्यात्मक प्रक्रिया |
| :--- | :--- | :--- | :--- |
| **ए + अ = अय्** | **नयन** | `ने + अन` | `न् + अय् + अन` = नयन |
| **ए + अ = अय्** | **शयन** | `शे + अन` | `श् + अय् + अन` = शयन |
| **ऐ + अ = आय्** | **नायक** | `नै + अक` | `न् + आय् + अक` = नायक |
| **ऐ + इ = आयि** | **गायिका** | `गै + इका` | `ग् + आय् + इका` = गायिका |
| **ओ + अ = अव्** | **पवन** | `पो + अन` | `प् + अव् + अन` = पवन |
| **ओ + अन = अव्**| **भवन** | `भो + अन` | `भ् + अव् + अन` = भवन |
| **ओ + इ = अवि** | **पवित्र** | `पो + इत्र` | `प् + अव् + इत्र` = पवित्र |
| **ओ + ई = अवी** | **गवीश** | `गो + ईश` | `ग् + अव् + ईश` = गवीश |
| **औ + अ = आव्** | **पावक** | `पौ + अक` | `प् + आव् + अक` = पावक (RAS 2021) |
| **औ + इ = आविष**| **नाविक** | `नौ + इक` | `न् + आव् + इक` = नाविक |
| **औ + उ = आवुक**| **भावुक** | `भौ + उक` | `भ् + आव् + उक` = भावुक |

</div>

> **[⚖️ अयादि संधि का विशिष्ट प्रत्यय नियम (वार्तिक: वांतो हि प्रत्यये)]**:  
> यदि 'ओ' या 'औ' के बाद 'य' से प्रारंभ होने वाला प्रत्यय आए, तो भी 'ओ' का 'अव्' और 'औ' का 'आव्' हो जाता है:  
> - `गो + यम्` = **गव्यम्** (गाय से प्राप्त)  
> - `नौ + य` = **नाव्य** (जो नाव द्वारा पार करने योग्य हो)

---

## 2.3 व्यंजन संधि महा-विज्ञान (Consonant Euphonic Combinations)

व्यंजन के बाद स्वर या व्यंजन आने पर व्यंजन में जो विकार होता है, उसे **व्यंजन संधि** कहते हैं। इसके **14 अचूक शास्त्रीय नियम** हैं:

---

### नियम 1: प्रथम वर्ण का तृतीय वर्ण में रूपान्तरण (*झलां जशोऽन्ते*)
जब किसी वर्ग के प्रथम वर्ण (`क्, च्, ट्, त्, प्`) के बाद कोई **स्वर**, किसी वर्ग का **तीसरा या चौथा वर्ण** (`ग, घ, ज, झ, ड, ढ, द, ध, ब, भ`), अथवा **अन्तःस्थ व्यंजन** (`य, र, ल, व, ह`) आए, तो प्रथम वर्ण अपने ही वर्ग के **तीसरे वर्ण (`ग्, ज्, ड्, द्, ब्`)** में बदल जाता है:

$$\mathbf{क् \rightarrow ग्, \quad च् \rightarrow ज्, \quad ट् \rightarrow ड्, \quad त् \rightarrow द्, \quad प् \rightarrow ब्}$$

* **क् $\rightarrow$ ग्**: `दिक् + गज` = **दिग्गज**, `वाक् + ईश` = **वागीश**, `दिक् + अंबर` = **दिगंबर** (RAS 2021), `ऋक् + वेद` = **ऋग्वेद**
* **च् $\rightarrow$ ज्**: `अच् + अंत` = **अजंत**, `अच् + आदि` = **अजादि**
* **ट् $\rightarrow$ ड्**: `षट् + आनन` = **षडानन** (RAS 2023), `षट् + रिपु` = **षड्रिपु**, `षट् + यंत्र` = **षड्यंत्र**
* **त् $\rightarrow$ द्**: `जगत् + ईश` = **जगदीश** (RAS 2021), `सत् + धर्म` = **सद्धर्म**, `सत् + भावना` = **सद्भावना**, `उत् + घाटन` = **उद्घाटन**, `भगवत् + गीता` = **भगवद्गीता**
* **प् $\rightarrow$ ब्**: `अप् + ज` = **अब्ज** (कमल: अप्=जल + ज=जन्मा), `अप् + द` = **अब्द** (बादल: अप्=जल + द=देने वाला), `सुप् + अंत` = **सुबंत**

---

### नियम 2: प्रथम वर्ण का पंचम वर्ण में रूपान्तरण (*यरोऽनुनासिकेऽनुनासिको वा*)
यदि किसी वर्ग के प्रथम वर्ण (`क्, च्, ट्, त्, प्`) के बाद कोई **नासिक्य व्यंजन (पंचमाक्षर — प्रायः 'न्' या 'म्')** आए, तो प्रथम वर्ण अपने ही वर्ग के **पांचवें वर्ण (`ङ्, ञ्, ण्, न्, म्`)** में बदल जाता है:

* **क् $\rightarrow$ ङ्**: `वाक् + मय` = **वाङ्मय** (साहित्य), `दिक् + नाग` = **दिङ्नाग**
* **ट् $\rightarrow$ ण्**: `षट् + मास` = **षण्मास**, `षट् + मूर्ति` = **षण्मूर्ति**, `षट् + मुख` = **षण्मुख**
* **त् $\rightarrow$ न्**: `जगत् + नाथ` = **जगन्नाथ**, `उत् + नति` = **उन्नति**, `सत् + मार्ग` = **सन्मार्ग**, `उत् + मेश` = **उन्मेष**
* **प् $\rightarrow$ म्**: `अप् + मय` = **अम्मय** (जलमय)

> **[⚡ RPSC TRAP ALERT: 'मृण्मय' का शुद्ध विच्छेद]**:  
> `मृण्मय` = **`मृत् + मय`** ('मृद् + मय' नहीं, क्योंकि संधि प्रथम वर्ण 'त्' से होती है; मृत् = मिट्टी)।

---

### नियम 3: 'त्' संबंधी 7 विशिष्ट शास्त्रीय नियम

<div style="overflow-x: auto;">

| क्र. | सूत्र | संधि पद | संधि-विच्छेद | विश्लेषण |
| :---: | :--- | :--- | :--- | :--- |
| **(i)** | **त् + च/छ = च्च/च्छ** | **उच्चारण**<br/>**सच्चरित्र**<br/>**तच्छत्र** | `उत् + चारण`<br/>`सत् + चरित्र`<br/>`तत् + छत्र` | 'त्' तालव्य 'च' में बदल जाता है। |
| **(ii)** | **त् + ज/झ = ज्ज** | **उज्ज्वल**<br/>**सज्जन**<br/>**विपज्जाल** | `उत् + ज्वल`<br/>`सत् + जन`<br/>`विपत् + जाल` | उज्ज्वल में दोनों 'ज्' आधे होते हैं (वर्तनी शुद्धि में अति-महत्वपूर्ण)! |
| **(iii)**| **त् + ट/ठ = ट्ट** | **तट्टीका**<br/>**बृहट्टीका** | `तत् + टीका`<br/>`बृहत् + टीका` | 'त्' मूर्धन्य 'ट' में बदल जाता है। |
| **(iv)** | **त् + ड/ढ = ड्ड** | **उड्डयन** | `उत् + डयन` | उड्डयन = ऊपर उड़ना |
| **(v)** | **त् + ल = ल्ल** | **उल्लास**<br/>**तल्लीन**<br/>**उल्लेख** | `उत् + लास`<br/>`तत् + लीन`<br/>`उत् + लेख` | 'त्' का पार्श्वीकरण होकर 'ल्ल' बनता है। |
| **(vi)** | **त् + श = च्छ** | **उच्छ्वास**<br/>**सच्छास्त्र**<br/>**उच्छिष्ट** | `उत् + श्वास`<br/>`सत् + शास्त्र`<br/>`उत् + शिष्ट` | **दोहरा विकार**: त् का 'च्' और श् का 'छ' हो जाता है (RAS 2023)! |
| **(vii)**| **त् + ह = द्ध** | **उद्धार**<br/>**तद्धित**<br/>**पद्धति** | `उत् + हार`<br/>`तत् + हित`<br/>`पत् + हति` | **दोहरा विकार**: त् का 'द्' और ह् का 'ध' हो जाता है (`द् + ध = द्ध`)! |

</div>

---

### नियम 4: 'म्' संबंधी अनुस्वार नियम
1. **म् + स्पर्श व्यंजन (क से म)**: 'म्' या तो अनुस्वार (ं) बनता है या परवर्ती वर्ग का पंचमाक्षर:  
   - `सम् + कल्प` = **संकल्प** (`सङ्कल्प`)  
   - `सम् + तोष` = **संतोष** (`सन्तोष`)  
   - `सम् + पूर्ण` = **संपूर्ण** (`सम्पूर्ण`)  
   - `सम् + गम` = **संगम** (`सङ्गम`)  
   - `सम् + बंध` = **संबंध** (`सम्बन्ध`)
2. **म् + अन्तःस्थ / ऊष्म (`य, र, ल, व, श, ष, स, ह`)**: 'म्' **अनिवार्यतः केवल अनुस्वार (ं)** बनता है (पंचमाक्षर में कभी नहीं बदलता!):  
   - `सम् + योग` = **संयोग**  
   - `सम् + रक्षण` = **संरक्षण**  
   - `सम् + लग्न` = **संलग्न**  
   - `सम् + वाद` = **संवाद**  
   - `सम् + शय` = **संशय**  
   - `सम् + हार` = **संहार**  
   - `सम् + सार` = **संसार**
3. **म् + म् = म्म (द्वित्व)**: जब 'म्' के बाद पुनः 'म' आए, तो अनुस्वार नहीं बनता, द्वित्व रहता है:  
   - `सम् + मान` = **सम्मान** (संमान अशुद्ध)  
   - `सम् + मति` = **सम्मति** (संमति अशुद्ध)  
   - `सम् + मुख` = **सम्मुख**

---

### नियम 5: 'छ' संबंधी तुक् (च्) आगम नियम
यदि किसी ह्रस्व स्वर (या 'आ') के बाद **'छ'** आए, तो दोनों के बीच **'च्'** का स्वतः आगम हो जाता है:

$$\mathbf{ह्रस्व \ स्वर / आ + छ \longrightarrow च्छ}$$

* `परि + छेद` = **परिच्छेद**
* `वि + छेद` = **विच्छेद**
* `अनु + छेद` = **अनुच्छेद**
* `तरु + छाया` = **तरुच्छाया**
* `मातृ + छाया` = **मातृच्छाया**
* `आ + छादन` = **आच्छादन**
* `वृक्ष + छाया` = **वृक्षच्छाया** (`क्ष` में अंत्य स्वर 'अ' है)

---

### नियम 6: दन्त्य 'स्' का मूर्धन्य 'ष्' में परिवर्तन
यदि 'स्' से पूर्व `अ / आ` से भिन्न कोई स्वर (प्रायः `इ` या `उ`) आए, तो दन्त्य **'स्'** मूर्धन्य **'ष्'** में बदल जाता है:

* `वि + सम` = **विषम**
* `सु + समा` = **सुषमा**
* `अभि + सेक` = **अभिषेक**
* `नि + सेध` = **निषेध**
* `अनु + संगी` = **अनुषंगी**
* `सु + सुप्ति` = **सुषुप्ति**
* *अपवाद*: `अनु + सरण` = **अनुसरण**, `अनु + स्वार` = **अनुस्वार**, `वि + स्मरण` = **विस्मरण**।

---

### नियम 7: 'न्' का 'ण्' में परिवर्तन (णत्व विधान)
यदि किसी शब्द में `ऋ`, `र्` अथवा `ष्` के बाद (चाहे बीच में स्वर, क-वर्ग, प-वर्ग, अन्तःस्थ या अनुस्वार का व्यवधान ही क्यों न हो) **'न्'** आए, तो वह 'न्' **'ण्'** में बदल जाता है:

* `परि + नाम` = **परिणाम**
* `प्र + मान` = **प्रमाण**
* `प्र + नाम` = **प्रणाम**
* `राम + अयन` = **रामायण** (दीर्घ स्वर संधि + णत्व विधान दोनों!)
* `ऋ + न` = **ऋण**
* `भूष् + अन` = **भूषण**
* `कृष् + न` = **कृष्ण**
* `शूर्प + नखा` = **शूर्पणखा** (शूर्प = सूप के समान नखों वाली)
* *अपवाद (त-वर्ग, च-वर्ग या श/स के व्यवधान पर णत्व नहीं होता)*: `दुर्जन`, `रत्न`, `अर्चना`।

---

## 2.4 विसर्ग संधि महा-विज्ञान (Visarga Euphonic Combinations)

विसर्ग (`:`) के बाद स्वर या व्यंजन आने पर विसर्ग में जो विकार होता है, उसे **विसर्ग संधि** कहते हैं। इसके **7 अचूक नियम** हैं:

---

### नियम 1: विसर्ग का 'ओ' में रूपान्तरण (*उत्व संधि*)
यदि विसर्ग से पूर्व **'अ'** हो और बाद में भी **'अ'** अथवा किसी वर्ग का **तीसरा, चौथा, पांचवां वर्ण ($3, 4, 5$)** या **`य, र, ल, व, ह`** आए, तो विसर्ग का 'उ' बनकर पूर्ववर्ती 'अ' के साथ मिलकर **'ओ'** हो जाता है:

$$\mathbf{अ + ः + सघोष \ व्यंजन \longrightarrow ओ}$$

* `मनः + अनुकूल` = **मनोनुकूल**
* `तपः + बल` = **तपोबल**
* `वयः + वृद्ध` = **वयोवृद्ध** (RAS 2021)
* `यशः + दा` = **यशोदा**
* `मनः + योग` = **मनोयोग**
* `सरः + वर` = **सरोवर**
* `पयः + धर` = **पयोधर**
* `मनः + हर` = **मनोहर**
* `तपः + भूमि` = **तपोभूमि** (RAS 2021)
* `यशः + लिप्सु` = **यशोलिप्सु** (RAS 2023)

> **[⚖️ उत्व संधि के दो महान अपवाद (पुनः एवं मुहुः)]**:  
> `पुनः` और `मुहुः` के विसर्ग का 'ओ' नहीं बनता, बल्कि **'र्' (रेफ)** बनता है:  
> - `पुनः + जन्म` = **पुनर्जन्म** ('पुनोजन्म' अशुद्ध)  
> - `पुनः + निर्माण` = **पुनर्निर्माण**  
> - `पुनः + अवलोकन` = **पुनरवलोकन** ('पुनरावलोकन' अशुद्ध वर्तनी है!)  
> - `मुहुः + मुहुः` = **मुहुर्मुहुः**

---

### नियम 2: विसर्ग का 'र्' में रूपान्तरण (*रुत्व संधि*)
यदि विसर्ग से पूर्व `अ / आ` को छोड़कर कोई अन्य स्वर (प्रायः `इ` या `उ`) हो और बाद में कोई **स्वर**, वर्ग का **तीसरा, चौथा, पांचवां वर्ण** या **`य, र, ल, व, ह`** आए, तो विसर्ग **'र्'** में बदल जाता है:

$$\mathbf{अ/आ \ भिन्न \ स्वर + ः + सघोष \longrightarrow र्}$$

* `निः + धन` = **निर्धन**
* `दुः + बल` = **दुर्बल**
* `निः + आशा` = **निराशा** (`निर् + आशा`)
* `दुः + आत्मा` = **दुरात्मा**
* `निः + झर` = **निर्झर**
* `आयुः + वेद` = **आयुर्वेद**
* `धनुः + धर` = **धनुर्धर**
* `बहिः + मुख` = **बहिर्मुख**
* `आशीः + वाद` = **आशीर्वाद** (रेफ 'व' पर लगेगा, 'शी' पर नहीं!)

---

### नियम 3: विसर्ग का तालव्य 'श्' होना (*श्चत्व संधि*)
यदि विसर्ग के बाद **`च, छ`** अथवा **`श`** आए, तो विसर्ग **तालव्य 'श्'** में बदल जाता है:

* `निः + चय` = **निश्चय**
* `हरिः + चन्द्र` = **हरिश्चन्द्र**
* `निः + छल` = **निश्छल**
* `दुः + चरित्र` = **दुश्चरित्र**
* `निः + शुल्क` = **निश्शुल्क** (अथवा विसर्ग सहित: `निःशुल्क`)
* `दुः + शासन` = **दुश्शासन** (अथवा `दुःशासन`)

---

### नियम 4: विसर्ग का मूर्धन्य 'ष्' होना (*षत्व संधि*)
यदि विसर्ग से पूर्व **`इ`** या **`उ`** हो और बाद में **`क, ख, ट, ठ, प, फ`** आए, तो विसर्ग **मूर्धन्य 'ष्'** में बदल जाता है:

* `निः + कपट` = **निष्कपट**
* `धनुः + टंकार` = **धनुष्टंकार** (RAS 2021)
* `निः + फल` = **निष्फल**
* `निः + पाप` = **निष्पाप**
* `दुः + कर्म` = **दुष्कर्म**
* `चतुः + पाद` = **चतुष्पाद**
* `आविः + कार` = **आविष्कार**
* `बहिः + कृत` = **बहिष्कृत**

---

### नियम 5: विसर्ग का दन्त्य 'स्' होना (*सत्व संधि*)
यदि विसर्ग के बाद **`त, थ`** अथवा **`स`** आए, तो विसर्ग **दन्त्य 'स्'** में बदल जाता है:

* `नमः + ते` = **नमस्ते**
* `निः + तेज` = **निस्तेज**
* `निः + संकोच` = **निस्संकोच** (अथवा `निःसंकोच`)
* `दुः + साहस` = **दुस्साहस** (अथवा `दुःसाहस`)
* `मनः + ताप` = **मनस्ताप**
* `अंतः + तल` = **अंतस्तल**

---

### नियम 6: विसर्ग लोप एवं पूर्व स्वर का दीर्घ होना
यदि विसर्ग से पूर्व ह्रस्व स्वर (`इ` या `उ`) हो और बाद में **'र'** आए, तो विसर्ग का **लोप** हो जाता है और पूर्ववर्ती ह्रस्व स्वर **दीर्घ (`ई` या `ऊ`)** बन जाता है:

$$\mathbf{इ/उ + ः + र \longrightarrow ई/ऊ + र \ (विसर्ग \ लोप)}$$

* `निः + रोग` = **नीरोग** ('निरोग' अशुद्ध वर्तनी है!)
* `निः + रस` = **नीरस** (RAS 2023)
* `निः + रव` = **नीरव**
* `निः + रज` = **नीरज**
* `चक्षुः + रोग` = **चक्षूरोग**

---

### नियम 7: विसर्ग का अविकारी (यथावत्) रहना
यदि विसर्ग से पूर्व **'अ'** हो और बाद में **`क, ख, प, फ`** आए, तो विसर्ग में **कोई विकार नहीं होता**, विसर्ग यथावत् बना रहता है:

* `प्रातः + काल` = **प्रातःकाल** ('प्रातोकाल' अशुद्ध)
* `पयः + पान` = **पयःपान** ('पयोपान' अशुद्ध)
* `मनः + कामना` = **मनःकामना** ('मनोकामना' व्याकरणिक दृष्टि से अशुद्ध है!)
* `अंतः + करण` = **अंतःकरण**
* `अधः + पतन` = **अधःपतन** ('अधोपतन' अशुद्ध)

## 2.5 हिन्दी की मौलिक (तद्भव) संधियां

हिन्दी में तत्सम संधियों के अतिरिक्त बोलचाल एवं तद्भव शब्दों में भी संधियां होती हैं, जो परीक्षा में प्रायः पूछी जाती हैं:

1. **'ह' का लोप एवं महाप्राणीकरण**:
   - `जब + ही` = **जभी**
   - `कब + ही` = **कभी**
   - `तब + ही` = **तभी**
   - `सब + ही` = **सभी**
   - `यहां + ही` = **यहीं**
   - `वहां + ही` = **वहीं**
2. **दीर्घ स्वर का ह्रस्व होना**:
   - `हाथ + कंडा` = **हथकंडा**
   - `कान + कटा` = **कनकटा**
   - `पानी + घाट` = **पनघट**
   - `आम + चूर` = **अमचूर**
   - `घोड़ा + दौड़` = **घुड़दौड़**
   - `मीठा + बोला` = **मिठबोला**
3. **स्वर लोप संधि**:
   - `उस + ही` = **उसी**
   - `इस + ही` = **इसी**
   - `किस + ही` = **किसी**

## 2.6 संधि-विच्छेद के 3 स्वर्णिम नियम (Deconstruction Mechanics)

1. **सार्थकता की कसौटी (Semantic Integrity)**:  
   संधि-विच्छेद करते समय दोनों खण्ड **सार्थक शब्द** होने चाहिए। निरर्थक खण्डों में तोड़ना अशुद्ध है।  
   *उदा.*: `उज्ज्वल` को `उज + वल` नहीं तोड़ा जा सकता; प्रामाणिक विच्छेद **`उत् + ज्वल`** है।
2. **मात्राओं की प्रामाणिकता (Orthographic Precision)**:  
   संधि-विच्छेद के उपरांत मूल शब्दों की प्रामाणिक मात्रा पहचानें:  
   - 'ईश', 'ईश्वर', 'ऊर्मि', 'ऊर्जा', 'ऊष्मा', 'ईक्षण' में **दीर्घ स्वर** होता है।  
   - 'इंद्र', 'इति', 'उदय', 'उत्सव', 'उत्तम' में **ह्रस्व स्वर** होता है।  
   - 'वधू', 'चमू', 'भू' में **दीर्घ स्वर** होता है।
3. **विकार की पहचान (Reverse Engineering)**:  
   - यदि बीच में `आ, ई, ऊ` दिखे $\rightarrow$ दीर्घ संधि की जांच करें।  
   - यदि बीच में `ए, ओ, अर्` दिखे $\rightarrow$ गुण संधि की जांच करें।  
   - यदि बीच में `ऐ, औ` दिखे $\rightarrow$ वृद्धि संधि की जांच करें।  
   - यदि `य, व, र` से पूर्व आधा वर्ण दिखे $\rightarrow$ यण संधि की जांच करें।  
   - यदि बीच में `अय, आय, अव, आव` की ध्वनि आए $\rightarrow$ अयादि संधि की जांच करें।

## 2.7 60-Second Retrieval Skeleton (द्रुत पुनरावलोकन)

```text
[स्वर संधि: 5] ── दीर्घ = सजातीय मिलकर दीर्घ (आ, ई, ऊ, ऋ)
                 गुण = अ/आ + इ/उ/ऋ ──> ए, ओ, अर्
                 वृद्धि = अ/आ + ए/ओ ──> ऐ, औ
                 यण = इ/उ/ऋ + असमान ──> य्, व्, र् (पूर्व वर्ण आधा)
                 अयादि = ए/ऐ/ओ/औ + स्वर ──> अय्, आय्, अव्, आव्

[व्यंजन संधि] ─── 1 का 3 = क्/च्/ट्/त्/प् + घोष ──> ग्/ज्/ड्/द्/ब्
                 1 का 5 = क्/ट्/त् + नासिक्य ──> ङ्/ण्/न्
                 त्-नियम = त्+च(च्च), त्+ज(ज्ज), त्+ल(ल्ल), त्+श(च्छ), त्+ह(द्ध)
                 म्-नियम = म्+स्पर्श(अनुस्वार/पंचम), म्+अन्तःस्थ/ऊष्म(केवल अनुस्वार)
                 तुक्-आगम = ह्रस्व स्वर + छ ──> च्छ (परिच्छेद, तरुच्छाया)
                 णत्व-नियम = ऋ/र्/ष् + न ──> ण (रामायण, परिणाम)

[विसर्ग संधि] ─── उत्व = अ + ः + घोष ──> ओ (तपोबल, वयोवृद्ध) [अपवाद: पुनः, मुहुः ──> र्]
                 रुत्व = भिन्न + ः + घोष ──> र् (निर्धन, आशीर्वाद)
                 शत्व = ः + च/छ/श ──> श् (निश्चय, हरिश्चन्द्र)
                 षत्व = इ/उ + ः + क/ट/प ──> ष् (निष्कपट, धनुष्टंकार)
                 सत्व = ः + त/थ/स ──> स् (नमस्ते, दुस्साहस)
                 लोप+दीर्घ = इ/उ + ः + र ──> ई/ऊ + र (नीरोग, नीरस)
                 अविकारी = अ + ः + क/प ──> ः (प्रातःकाल, मनःकामना, अंतःकरण)
```
