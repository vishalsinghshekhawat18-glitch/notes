## 4.1 प्रत्यय की तात्विक अवधारणा (Suffix Morphology)

### 1. परिभाषा एवं स्वरूप:
वे शब्दांश जो किसी धातु (क्रिया के मूल रूप) अथवा प्रातिपदिक (संज्ञा, सर्वनाम, विशेषण) के **अंत (परवर्ती भाग)** में जुड़कर नए शब्दों की रचना करते हैं, **प्रत्यय** कहलाते हैं:
$$\mathbf{मूल \ धातु / शब्द} + \mathbf{प्रत्यय \ (Suffix)} \longrightarrow \mathbf{नवीन \ व्युत्पन्न \ शब्द}$$

> **[⚖️ उपसर्ग बनाम प्रत्यय का मौलिक अंतर]**:  
> 1. उपसर्ग शब्द के **प्रारंभ** में जुड़ता है; प्रत्यय शब्द के **अंत** में जुड़ता है।  
> 2. उपसर्ग जुड़ने पर प्रायः संधि के सामान्य नियम लागू होते हैं; प्रत्यय जुड़ने पर **आदिवृद्धि (स्वर वृद्धि)** एवं **अंतिम स्वर का लोप** जैसे विशिष्ट रूपान्तरण नियम लागू होते हैं।  
> 3. उपसर्गों का अपना कुछ स्वतंत्र अर्थ हो सकता है (`अति` = अधिक, `दुर्` = बुरा); प्रत्ययों का स्वतंत्र अर्थ नहीं होता, वे केवल व्याकरणिक कोटि (संज्ञा से विशेषण, भाववाचक आदि) बदलते हैं।

---

### 2. प्रत्यय के दो सार्वभौमिक भेद:

```text
                           ┌───────────────────────────┐
                           │      प्रत्यय के मूल भेद    │
                           └─────────────┬─────────────┘
                                         │
                 ┌───────────────────────┴───────────────────────┐
                 ▼                                               ▼
       [कृत् प्रत्यय / कृदन्त]                        [तद्धित प्रत्यय / तद्धितान्त]
  जो क्रिया या धातु के अंत में जुड़ते हैं।        जो संज्ञा, सर्वनाम या विशेषण के अंत में जुड़ते हैं।
    (उदा. पढ़् + आई = पढ़ाई)                       (उदा. सुंदर + ता = सुंदरता, मानव + ता = मानवता)
```

## 4.2 कृत् प्रत्यय महा-विज्ञान (Krit Pratyaya — 5 प्रकार)

क्रिया या धातु के अंत में जुड़ने वाले प्रत्यय **कृत् प्रत्यय** कहलाते हैं और इनसे बने शब्दों को **कृदन्त** (कृत् + अंत) कहा जाता है।

<div style="overflow-x: auto;">

| भेद | कार्य / लक्षण | प्रयुक्त प्रमुख प्रत्यय | प्रामाणिक उदाहरण |
| :--- | :--- | :--- | :--- |
| **1. कर्तृवाचक कृदन्त** | कार्य करने वाले (कर्ता) का बोध कराने वाले | **अक, अक्कड़, आऊ, आक, आका, आलू, इयल, एरा, वैया, वाला** | `लिख् + अक` = **लेखक**, `भूल + अक्कड़` = **भुलक्कड़**, `तैर + आक` = **तैराक**, `लड़ + आका` = **लड़ाका**, `अड़ + इयल` = **अड़ियल**, `लूटना + एरा` = **लुटेरा**, `रखना + वाला` = **रखवाला** |
| **2. कर्मवाचक कृदन्त** | क्रिया के कर्म (जिस पर क्रिया का फल पड़े) का बोध | **औना, ना, नी** | `खेल + औना` = **खिलौना**, `बिछा + औना` = **बिछौना**, `पढ़ + ना` = **पढ़ना**, `ओढ़ + नी` = **ओढ़नी** |
| **3. करणवाचक कृदन्त** | क्रिया के साधन (माध्यम) का बोध कराने वाले | **आ, उ, न, नी** | `झूल + आ` = **झूला**, `झाड़ + उ` = **झाड़ू**, `बेल + न` = **बेलन**, `कतर + नी` = **कतरनी**, `मथ + नी` = **मथनी** |
| **4. भाववाचक कृदन्त** | क्रिया के भाव या व्यापार का बोध कराने वाले | **अन्त, आई, आन, आप, आव, आवट, आहट, औती, ई** | `भिड़ + अन्त` = **भिड़न्त**, `पढ़ + आई` = **पढाई**, `उड़ + आन` = **उड़ान**, `मिल + आप` = **मिलाप**, `बहा + आव` = **बहाव**, `लिख + आवट` = **लिखावट**, `घबरा + आहट` = **घबराहट**, `हंस + ई` = **हंसी** |
| **5. क्रियाद्योतक कृदन्त**| क्रिया के होने का भाव दर्शाने वाले | **ता, ती, ते, कर, या** | `पढ़ + ता` = **पढ़ता**, `गा + कर` = **गाकर**, `खा + या` = **खाया**, `रो + ते` = **रोते** |

</div>

## 4.3 तद्धित प्रत्यय महा-विज्ञान (Taddhit Pratyaya — 6 प्रकार)

संज्ञा, सर्वनाम अथवा विशेषण के अंत में जुड़कर नए शब्द बनाने वाले प्रत्यय **तद्धित प्रत्यय** कहलाते हैं और इनसे बने शब्दों को **तद्धितान्त** (तद्धित + अंत) कहा जाता है।

<div style="overflow-x: auto;">

| भेद | कार्य / लक्षण | प्रमुख प्रत्यय | प्रामाणिक उदाहरण |
| :--- | :--- | :--- | :--- |
| **1. कर्तृवाचक तद्धितान्त** | संज्ञा आदि से कर्ता का निर्माण | **आर, इया, ई, एरा, ची, गार, दार** | `लोहा + आर` = **लुहार**, `सोना + आर` = **सुनार**, `मुखिया`, `तेली`, `सपेरा`, `मशालची`, `जादूगर`, `दुकानदार` |
| **2. भाववाचक तद्धितान्त** | संज्ञा/विशेषण से भाववाचक संज्ञा | **आई, आपा, आस, आहट, ई, ता, त्व, पन** | `बुरा + आई` = **बुराई**, `बूढ़ा + आपा` = **बुढ़ापा**, `मीठा + आस` = **मिठास**, `कड़वा + आहट` = **कड़वाहट**, `सुंदर + ता` = **सुंदरता**, `मनुष्य + त्व` = **मनुष्यत्व**, `लड़का + पन` = **लड़कपन** |
| **3. संबंधवाचक तद्धितान्त**| संबंध अथवा संसर्ग का बोध | **इक, इत, ई, एरा, ला, आल, औती** | `समाज + इक` = **सामाजिक**, `शारीरिक`, `चाचा + एरा` = **चचेरा**, `मामा + एरा` = **ममेरा**, `ससुर + आल` = **ससुराल**, `बाप + औती` = **बपौती** |
| **4. अपत्यवाचक (संतानबोधक)**| वंशज, संतान या संप्रदाय का बोध | **अ, इ, ई, एय, आयन** | `मनु + अ` = **मानव**, `दशरथ + इ` = **दाशरथि**, `कुंती + एय` = **कौंतेय**, `जनक + ई` = **जानकी**, `राधा + एय` = **राधेय** |
| **5. उनवाचक (लघुताबोधक)** | बड़ी वस्तु से छोटी (लघु) का बोध | **इया, ई, ओला, री, टी** | `खाट + इया` = **खटिया**, `डिब्बा + इया` = **डिबिया**, `रस्सा + ई` = **रस्सी**, `खाट + ओला` = **खटोला**, `कोठा + री` = **कोठरी** |
| **6. स्त्रीबोधक तद्धितान्त**| पुल्लिंग से स्त्रीलिंग का निर्माण | **आ, आनी, इन, ई, नी, आइन** | `सुत + आ` = **सुता**, `सेठ + आनी` = **सेठानी**, `धोबी + इन` = **धोबिन**, `मोर + नी` = **मोरनी**, `पंडित + आइन` = **पंडिताइन** |

</div>

## 4.4 आदिवृद्धि प्रत्यय महा-विधान (Initial Vowel Lengthening Law)

यह RPSC RAS Mains का **सर्वाधिक अंकदायी एवं जटिलतम नियम** है।

### सार्वभौमिक नियम:
जब किसी शब्द में विशिष्ट प्रत्यय (विशेष रूप से **`इक, य, अ, ई, एय, आयन`**) जुड़ते हैं, तो शब्द के **प्रथम स्वर (आदि स्वर)** में अनिवार्य रूप से **वृद्धि (दीर्घीकरण)** हो जाती है तथा **अंतिम स्वर का लोप** हो जाता है:

$$\mathbf{अ / आ \longrightarrow आ} \qquad \mathbf{इ / ई / ए \longrightarrow ऐ} \qquad \mathbf{उ / ऊ / ओ \longrightarrow औ} \qquad \mathbf{ऋ \longrightarrow आर्}$$

---

### 1. 'इक' प्रत्यय का आदिवृद्धि चमत्कार:

<div style="overflow-x: auto;">

| प्रथम स्वर परिवर्तन | मूल शब्द | 'इक' प्रत्यय युक्त सिद्ध पद | परीक्षा टिप्पणी / विश्लेषण |
| :---: | :--- | :--- | :--- |
| **अ $\rightarrow$ आ** | **समाज** | **सामाजिक** | 'स' का 'सा' होना अनिवार्य है (सामाजिक शुद्ध) |
| **अ $\rightarrow$ आ** | **अध्यात्म** | **आध्यात्मिक** | 'अ' का 'आ' होना (आध्यात्मिक शुद्ध) |
| **अ $\rightarrow$ आ** | **प्रमाण** | **प्रामाणिक** | 'प्रमाणिक' अशुद्ध वर्तनी है! |
| **अ $\rightarrow$ आ** | **दण्ड** | **दाण्डिक** | दाण्डिक न्यायालय (दण्ड प्रक्रिया) |
| **अ $\rightarrow$ आ** | **व्यवहार** | **व्यावहारिक** | `व्य` = `व् + अ` $\rightarrow$ 'व् + आ' = 'व्या' |
| **अ $\rightarrow$ आ** | **व्यवसाय** | **व्यावसायिक** | व्यावसायिक शिक्षा |
| **अ $\rightarrow$ आ** | **सप्ताह** | **साप्ताहिक** | साप्ताहिक पत्रिका |
| **इ $\rightarrow$ ऐ** | **इतिहास** | **ऐतिहासिक** | 'इ' का 'ऐ' होना |
| **इ $\rightarrow$ ऐ** | **दिन** | **दैनिक** | दैनिक समाचार |
| **इ $\rightarrow$ ऐ** | **विज्ञान** | **वैज्ञानिक** | 'वि' का 'वै' होना |
| **ई $\rightarrow$ ऐ** | **ईश्वर** | **ऐश्वर्य** ('य' में) / **ऐहिक** (`इह+इक`)| ईहलोक से संबंधित |
| **ए $\rightarrow$ ऐ** | **वेद** | **वैदिक** | वेदों से संबंधित |
| **ए $\rightarrow$ ऐ** | **देह** | **दैहिक** | दैहिक, दैविक, भौतिक |
| **उ $\rightarrow$ औ** | **उपन्यास** | **औपन्यासिक** | 'उ' का 'औ' होना |
| **उ $\rightarrow$ औ** | **उद्योग** | **औद्योगिक** | 'औद्योगिक' शुद्ध |
| **उ $\rightarrow$ औ** | **उपचार** | **औपचारिक** | औपचारिकता |
| **ऊ $\rightarrow$ औ** | **मूल** | **मौलिक** | मौलिक अधिकार |
| **ऊ $\rightarrow$ औ** | **भूत** | **भौतिक** | भौतिक विज्ञान |
| **ओ $\rightarrow$ औ** | **भूगोल** | **भौगोलिक** | 'गो' का 'गौ' नहीं, प्रथम स्वर 'भू' का 'भौ' होगा! |
| **ओ $\rightarrow$ औ** | **लोक** | **लौकिक** | सांसारिक |

### 2. 'य' प्रत्यय का विशिष्ट द्विविध नियम (The Two-Fold 'Ya' Law)
जब किसी शब्द में **'य'** प्रत्यय जुड़ता है, तो दो घटनाएं एक साथ घटित होती हैं:
1. **प्रथम स्वर में आदिवृद्धि** होती है ($अ \rightarrow आ$, $इ/ई/ए \rightarrow ऐ$, $उ/ऊ/ओ \rightarrow औ$, $ऋ \rightarrow आर्$)।
2. **अंतिम वर्ण अनिवार्य रूप से आधा (स्वर-रहित)** हो जाता है!

$$\mathbf{मूल \ शब्द} + \mathbf{य} \longrightarrow \mathbf{आदिवृद्धि + अंतिम \ वर्ण \ आधा + य}$$

<div style="overflow-x: auto;">

| मूल शब्द | 'य' प्रत्यय संयोजन | अंतिम निष्पन्न पद | व्याकरणिक प्रक्रिया |
| :--- | :---: | :--- | :--- |
| **सुंदर** | `सुंदर + य` | **सौंदर्य** | 'सु' का 'सौ', 'र' आधा होकर 'य' के सिर पर रेफ बना। |
| **धीर** | `धीर + य` | **धैर्य** | 'धी' का 'धै', 'र' आधा रेफ बना। |
| **उदार** | `उदार + य` | **औदार्य** | 'उ' का 'औ', 'र' आधा रेफ बना। |
| **मधुर** | `मधुर + य` | **माधुर्य** | 'म' का 'मा', 'र' आधा रेफ बना। |
| **समान** | `समान + य` | **साम्य** | 'स' का 'सा', अंत्य 'न' का लोप, 'म' आधा! |
| **पंडित** | `पंडित + य` | **पांडित्य** | 'पं' का 'पां', अंत्य 'त' आधा। |
| **कवि** | `कवि + य` | **काव्य** | 'क' का 'का', अंत्य 'व' आधा। |
| **ईश्वर** | `ईश्वर + य` | **ऐश्वर्य** | 'ई' का 'ऐ', अंत्य 'र' रेफ बना। |
| **महात्मा** | `महात्मा + य`| **माहात्म्य** | 'म' का 'मा', अंत्य 'त' आधा, 'म' आधा! |
| **पृथक** | `पृथक + य` | **पार्थक्य** | 'ऋ' का 'आर्', अंत्य 'क' आधा। |
| **गृहस्थ** | `गृहस्थ + य` | **गार्हस्थ्य** | 'ऋ' का 'आर्', अंत्य 'थ' आधा। |
| **शूर** | `शूर + य` | **शौर्य** | 'शू' का 'शौ', 'र' आधा रेफ। |
| **विधवा** | `विधवा + य` | **वैधव्य** | 'वि' का 'वै', 'व' आधा। |

</div>

## 4.6 60-Second Retrieval Skeleton (द्रुत पुनरावलोकन)

```text
[प्रत्यय के दो भेद] ── कृत् प्रत्यय (क्रिया/धातु के अंत में: कृदन्त)
                      तद्धित प्रत्यय (संज्ञा/सर्वनाम/विशेषण के अंत में: तद्धितान्त)

[आदिवृद्धि सूत्र] ──── अ/आ ──> आ (सामाजिक, प्रामाणिक, व्यावहारिक, आध्यात्मिक)
                      इ/ई/ए ──> ऐ (ऐतिहासिक, दैनिक, वैज्ञानिक, वैदिक)
                      उ/ऊ/ओ ──> औ (भौगोलिक, औपन्यासिक, मौलिक, औद्योगिक)
                      ऋ ──> आर् (गार्हस्थ्य, पार्थक्य)

['य' प्रत्यय नियम] ── आदिवृद्धि + अंतिम वर्ण आधा (सौंदर्य, धैर्य, माधुर्य, साम्य, माहात्म्य)

[अपत्यवाचक] ──────── मनु ──> मानव | रघु ──> राघव | कुंती ──> कौंतेय | दशरथ ──> दाशरथि

[द्वित्व प्रत्यय वर्जना] सौंदर्यता ❌ (सौंदर्य / सुंदरता ✅) | ऐक्यता ❌ (ऐक्य / एकता ✅) | 
                      सौजन्यता ❌ (सौजन्य / सुजनता ✅)
```

## 4.7 सक्रिय स्मरण एवं अभ्यास ड्रिल (Active Recall Drill)

1. **प्रश्न**: 'प्रामाणिक' में कौन-सा मूल शब्द एवं प्रत्यय है?  
   *उत्तर*: मूल शब्द = **`प्रमाण`**, प्रत्यय = **`इक`** (आदिवृद्धि से 'प्र' का 'प्रा' हुआ; 'प्रमाणिक' अशुद्ध है)।
2. **प्रश्न**: 'सौंदर्यता' शब्द शुद्ध है अथवा अशुद्ध? सकारण स्पष्ट कीजिए।  
   *उत्तर*: **अशुद्ध** है। इसमें 'य' और 'ता' दो भाववाचक प्रत्ययों का द्वित्व दोष है। शुद्ध रूप **`सौंदर्य`** अथवा **`सुंदरता`** है।
3. **प्रश्न**: 'कौंतेय' में मूल शब्द एवं प्रत्यय बताइए।  
   *उत्तर*: मूल शब्द = **`कुंती`**, प्रत्यय = **`एय`** (अपत्यवाचक तद्धित प्रत्यय)।
4. **प्रश्न**: 'माहात्म्य' का प्रकृति-प्रत्यय विच्छेद कीजिए।  
   *उत्तर*: **`महात्मा + य`** (आदिवृद्धि से 'म' का 'मा' तथा अंत्य 'त' व 'म' आधे)।
5. **प्रश्न**: 'राघव' में कौन-सा प्रत्यय है?  
   *उत्तर*: **`अ`** प्रत्यय (`रघु + अ = राघव`, अपत्यवाचक)।
