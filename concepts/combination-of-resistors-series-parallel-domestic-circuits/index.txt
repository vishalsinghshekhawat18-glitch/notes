11:T413,### Comparison of Circuit Topologies

| Circuit Parameter | Series Circuit ($R_s$) | Parallel Circuit ($R_p$) |
| :--- | :--- | :--- |
| **Current ($I$)** | **CONSTANT / SAME** through all components ($I_1 = I_2 = I$). | **DIVIDED** across branches: $\mathbf{I = I_1 + I_2 + \dots}$ |
| **Voltage ($V$)** | **DIVIDED** across components: $\mathbf{V = V_1 + V_2 + \dots}$ | **CONSTANT / SAME** across all branches ($V_1 = V_2 = V$). |
| **Equivalent Formula**| $\mathbf{R_s = R_1 + R_2 + R_3 + \dots}$ | $\mathbf{\frac{1}{R_p} = \frac{1}{R_1} + \frac{1}{R_2} + \dots}$ |
| **Two Resistor Shortcut**| $R_s = R_1 + R_2$ | $\mathbf{R_p = \frac{R_1 R_2}{R_1 + R_2}}$ *(Product / Sum)* |
| **$n$ Identical Resistors ($R$)**| $R_s = n \cdot R$ | $R_p = \frac{R}{n}$ |
| **Net Magnitude** | **Larger than the largest resistor** ($R_s > R_{\text{max}}$). | **Smaller than the smallest resistor** ($R_p < R_{\text{min}}$). |
| **Appliance Failure** | If one component fails, **entire circuit dies**. | If one component fails, **others work normally**.
