```
          ┌───────────────────────────────────────────────┐
          │               ATTITUDE OBJECT                 │
          │     (e.g., Girl Child Education, Tax Paying)   │
          └───────────────────────┬───────────────────────┘
                                  │
         ┌────────────────────────┼────────────────────────┐
         ↓                        ↓                        ↓
   [ COGNITIVE ]            [ AFFECTIVE ]            [ BEHAVIORAL ]
  Thoughts, beliefs,      Emotions, feelings,       Predisposition to act,
  facts, rational data    prejudices, visceral      observed habits,
  (e.g., 'Educating girls   reactions (e.g., pride  action tendencies (e.g.,
  raises GDP')            in daughters)             enrolling girl in school)
```

### 2. Daniel Katz's Four Functional Foundations

| Function | Psychological Purpose | Administrative Example |
| :--- | :--- | :--- |
| **Utilitarian (Instrumental)** | Attain rewards, avoid punishments | Citizens adopting solar energy because of government subsidies (*KUSUM scheme*) |
| **Ego-Defensive** | Protect self-esteem from harsh truths or guilt | Corrupt officials rationalizing bribery by claiming 'everyone takes money' |
| **Value-Expressive** | Publicly express self-identity and core ethics | Civil servants actively volunteering for disaster relief in Barmer floods |
| **Knowledge** | Provide simple cognitive shortcuts for a complex world | Classifying citizens based on past experiences to streamline grievance triage
