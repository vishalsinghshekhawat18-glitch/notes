12:T465,### The Genetic Hierarchy: From Nucleotide to Chromosome

```
       CELL NUCLEUS
            │
            ▼
       CHROMOSOMES (46 in humans; visible during cell division)
            │
            ▼
       CHROMATIN (DNA wrapped around basic HISTONE proteins)
            │
            ▼
       DNA DOUBLE HELIX (Deoxyribonucleic Acid)
            │
            ▼
       GENES (Functional segments coding for specific proteins)
````

| Component | Physical Description | Core Biological Function |
| :--- | :--- | :--- |
| **Nuclear Envelope** | Double membrane with nuclear pores | Isolates genetic material; regulates RNA/protein exchange. |
| **Nucleolus** | Dense spherical body inside nucleus | **"Ribosome Factory"** (synthesizes ribosomal RNA / rRNA). |
| **Chromatin** | Entangled thread network | Form of DNA in resting, non-dividing cells (*Interphase*). |
| **Chromosomes** | Condensed rod-shaped structures | Ensures exact, equal segregation of DNA during cell division. |
| **Genes** | Specific sequences of DNA base pairs | **Functional units of heredity** passed from parents to offspring.
