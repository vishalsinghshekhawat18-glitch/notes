12:T8ff,### 1. Essential Algebraic Identities
- **Square Identities:**
  - $(a + b)^2 = a^2 + 2ab + b^2$
  - $(a - b)^2 = a^2 - 2ab + b^2$
  - $a^2 - b^2 = (a + b)(a - b)$
  - $(a + b)^2 - (a - b)^2 = 4ab$
  - $(a + b)^2 + (a - b)^2 = 2(a^2 + b^2)$
- **Reciprocal Identity Chains ($x + 1/x = k$):**
  - $x^2 + rac{1}{x^2} = k^2 - 2$
  - $x^3 + rac{1}{x^3} = k^3 - 3k$
  - *(If $x - 1/x = k$, then $x^2 + 1/x^2 = k^2 + 2$ and $x^3 - 1/x^3 = k^3 + 3k$)*.
- **Cubic Identities:**
  - $a^3 + b^3 = (a + b)(a^2 - ab + b^2)$
  - $a^3 - b^3 = (a - b)(a^2 + ab + b^2)$
  - $a^3 + b^3 + c^3 - 3abc = (a + b + c)(a^2 + b^2 + c^2 - ab - bc - ca)$
  - *(If $a + b + c = 0$, then $a^3 + b^3 + c^3 = 3abc$)*.

### 2. Quadratic Equation Fundamentals ($ax^2 + bx + c = 0$)
- **Quadratic Formula:** $x = rac{-b pm sqrt{D}}{2a}$, where Discriminant $D = b^2 - 4ac$.
- **Sum & Product of Roots:**
  - Sum of roots: $alpha + eta = -rac{b}{a}$
  - Product of roots: $alpha cdot eta = rac{c}{a}$
- **Nature of Roots:**
  - $D > 0 implies$ Real & distinct roots.
  - $D = 0 implies$ Real & equal roots ($alpha = eta = -b/2a$).
  - $D < 0 implies$ No real roots (imaginary).
  - $D$ is a perfect square $implies$ Rational roots.

> If the constant term ($c$) is **NEGATIVE** in BOTH equations:
> $$a_1 x^2 + b_1 x - c_1 = 0 quad 	ext{and} quad a_2 y^2 + b_2 y - c_2 = 0$$
> The roots will automatically be:
> $$x in {-alpha_1, +eta_1} quad 	ext{and} quad y in {-alpha_2, +eta_2}$$
> Because positive $x$ exceeds negative $y$, but positive $y$ exceeds negative $x$, the intervals overlap.
