11:T443,### The Lens Formula vs Mirror Formula Comparison:

| Feature | Spherical Lenses (Refraction) | Spherical Mirrors (Reflection) |
| :--- | :---: | :---: |
| **Formula** | $\mathbf{\frac{1}{f} = \frac{1}{v} - \frac{1}{u}}$ | $\frac{1}{f} = \frac{1}{v} + \frac{1}{u}$ |
| **Magnification ($m$)** | $\mathbf{m = +\frac{v}{u}}$ | $m = -\frac{v}{u}$ |
| **Convex Element** | **Converging ($f > 0, P > 0$)** | Diverging ($f > 0, P = 0$) |
| **Concave Element** | **Diverging ($f < 0, P < 0$)** | Converging ($f < 0, P = 0$) |

### Power of a Lens Formula:
$$\mathbf{P = \frac{1}{f \text{ (in metres)}}} \quad \left[\text{SI Unit: Dioptre (D)} = \text{m}^{-1}\right]$$
- If focal length $f$ is given in centimetres: $P = \frac{100}{f \text{ (in cm)}}$.
- **Convex Lens of $f = +50 \, \text{cm} = +0.5 \, \text{m}$**: $P = \frac{1}{+0.5} = \mathbf{+2.0 \, \text{D}}$.
- **Concave Lens of $f = -20 \, \text{cm} = -0.2 \, \text{m}$**: $P = \frac{1}{-0.2} = \mathbf{-5.0 \, \text{D}}$.
- **Combination of Lenses in Contact**: $P_{\text{total}} = P_1 + P_2 = (+2.0) + (-5.0) = \mathbf{-3.0 \, \text{D}}$.12:T40d,### 1. Convex (Converging) Lens Image Behavior
- Object at $\infty \implies$ Real, inverted, point image at $F_2$.
- Object beyond $2F_1 \implies$ Real, inverted, diminished image between $F_2$ and $2F_2$ (Camera lens).
- Object at $2F_1 \implies$ Real, inverted, same size image at $2F_2$ ($m = -1$).
- Object between $F_1$ and $2F_1 \implies$ Real, inverted, enlarged image beyond $2F_2$ (Slide projector).
- Object at $F_1 \implies$ Real, inverted, infinitely large image at $\infty$ (Searchlight collimator).
- **Object between Optical Centre ($O$) and Focus ($F_1$)**:
  - Forms a **Virtual, Erect, and Enlarged** image on the same side as the object ($m > +1$).
  - **This is the Simple Microscope / Hand Magnifying Glass!**

### 2. Concave (Diverging) Lens Image Behavior
- For ALL object positions anywhere in front of the lens:
  - **ALWAYS forms a Virtual, Erect, and Diminished image** between optical centre $O$ and focus $F_1$ on the same side as object ($0 < m < +1$).
  - Used for **Myopia (Near-sightedness)
