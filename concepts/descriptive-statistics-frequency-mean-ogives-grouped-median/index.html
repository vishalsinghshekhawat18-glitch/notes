Descriptive Statistics: Frequency Distributions, Direct/Step-Deviation Mean, Cumulative Frequencies & Grouped Median Interpolation

Rigorous statistical foundations covering discrete and continuous frequency tables, class marks, direct, assumed mean, and step-deviation arithmetic means, cumulative frequency ogives, and ungrouped vs grouped linear median interpolation.

Intuition & Context

Compressing Raw Observations into Structural Distributions

Imagine auditing 10,000 retail loan applications or recording daily temperatures across 365 days. Raw unordered lists are practically uninterpretable. By grouping observations into class intervals (e.g., [10-20), [20-30)) and counting frequencies f_i, we transform unstructured noise into a condensed mathematical frequency distribution.\n\nHowever, condensation introduces a fundamental challenge: once data is grouped into classes, individual raw values are hidden. To compute summary measures like the arithmetic mean and median, statistics uses rigorous mathematical proxies—class marks (midpoints) for mean calculations, and proportional linear interpolation across the cumulative frequency distribution for median partitions.

Core Principle

Class Marks, Arithmetic Mean Methods & Cumulative Frequency Distributions

  1. Class Intervals and Class Marks:\nFor continuous grouped data with class interval [L, U):\n- Lower limit = L, Upper limit = U.\n- Class mark (midpoint) x_i = (L + U) / 2.\n- Class width (size) h = U - L (assumed uniform across classes).\n\n2. Three Equivalent Formulations of Arithmetic Mean:\n- Direct Method:\n Mean x_bar = (sum(f_i * x_i)) / N, where N = sum(f_i).\n- Assumed Mean Method (Deviation Method):\n Choose assumed mean A from class marks. Define deviation d_i = x_i - A.\n Mean x_bar = A + (sum(f_i * d_i)) / N.\n- Step-Deviation Method:\n When class width h is uniform, define coded step u_i = (x_i - A) / h.\n Mean x_bar = A + [ (sum(f_i * u_i)) / N ] * h.\n\n3. Cumulative Frequency Distributions:\n- "Less Than" Cumulative Frequency: Sum frequencies of all classes up to the upper limit of the current class. Plotted against Upper Limits.\n- "More Than" Cumulative Frequency: Sum frequencies of all classes from the lower limit of the current class up to the maximum. Plotted against Lower Limits.
How It Works / Mechanism

Grouped Median Interpolation & Ogive Curve Intersections

  1. Ungrouped Median:\nFor n ordered observations:\n- If n is odd: Median = Value at position (n + 1) / 2.\n- If n is even: Median = Arithmetic average of values at positions (n / 2) and (n / 2 + 1).\n\n2. Grouped Median Linear Interpolation:\nIdentify the median class: the first class whose cumulative frequency cf >= N / 2, where N = sum(f_i).\nUnder the uniform density assumption across the median interval [L, U), the median is given by:\nMedian = L + [ ( (N / 2) - cf_prev ) / f_m ] * h\nwhere:\n- L = lower boundary of the median class\n- N = total frequency sum(f_i)\n- cf_prev = cumulative frequency of the class strictly PRECEDING the median class\n- f_m = frequency of the median class itself\n- h = class width of the median class\n\n3. Ogive Intersection Invariant:\nWhen the "Less than ogive" (monotonically increasing) and the "More than ogive" (monotonically decreasing) are plotted on the same Cartesian coordinate axes (X-axis = class boundaries, Y-axis = cumulative frequency):\n- The two ogive curves intersect at a point P(x_0, y_0).\n- The ordinate (Y-coordinate) of intersection is exactly N / 2.\n- The abscissa (X-coordinate) x_0 projected onto the horizontal axis is strictly the MEDIAN of the distribution.\n\n4. Empirical Relationship (Pearson Empirical Rule):\nFor moderately skewed unimodal frequency distributions:\nMode = 3 * Median - 2 * Mean

Exam Trap & High-Yield Analysis

Competitive Examination Archetypes & Traps

  1. Trap 1: Cumulative Frequency Substitution in Median Formula:\nStudents frequently substitute the cumulative frequency of the median class itself rather than cf_prev (the cumulative frequency of the preceding class). Always double check: cf_prev < N / 2.\n\n2. Trap 2: Inclusive vs Exclusive Class Intervals:\nIf given inclusive classes like 10-19, 20-29, 30-39, you MUST convert them to true continuous boundaries (exclusive intervals) before calculating L or h:\nLower limit L becomes 19.5, upper limit becomes 29.5, width h = 10 (not 9!).\n\n3. Trap 3: Direct Ogive Identification:\nQuestions in SSC CGL and banking often ask: "The abscissa of the point of intersection of less-than and more-than ogives gives which measure of central tendency?" Options: Mean, Median, Mode, Geometric Mean. The correct invariant is strictly the MEDIAN.\n\n4. Trap 4: Step-Deviation Class Width Multiplication:\nWhen calculating mean via step-deviation x_bar = A + [ sum(f_i * u_i) / N ] * h, students regularly forget to multiply the bracketed summation quotient by class width h before adding assumed mean A.
