सन्धि एवं सन्धि-विच्छेद

वर्णों के मेल से उत्पन्न विकार, स्वर सन्धि (दीर्घ, गुण, वृद्धि, यण, अयादि) के सूत्र व नियम।

सन्धि एवं सन्धि-विच्छेद · Concept 1 of 2

सन्धि एवं सन्धि-विच्छेद — स्वर सन्धि के पांच भेद (दीर्घ, गुण, वृद्धि, यण, अयादि)

दो स्वरों के पारस्परिक व्यवधानरहित मेल से उत्पन्न ध्वनि-परिवर्तन (विकार): दीर्घ (सजातीय दीर्घीकरण), गुण (ए, ओ, अर्), वृद्धि (ऐ, औ), यण (इ/उ/ऋ का य्/व्/र्) एवं अयादि (ए/ऐ/ओ/औ का अय्/आय्/अव्/आव्)।

Intuition & Context

स्वर सन्धि का ध्वन्यात्मक आधार: वाक्-प्रवाह में ऊर्जा-संरक्षण एवं उच्चारण-सुगमता

जब हम तीव्र गति से दो शब्दों का उच्चारण करते हैं, तो प्रथम शब्द की अंतिम ध्वनि और द्वितीय शब्द की प्रथम ध्वनि एक-दूसरे के इतने सन्निकट आ जाती हैं कि हमारा मुख-विवर ऊर्जा बचाने (Economy of Effort / Law of Least Effort) हेतु दोनों ध्वनियों को मिलाकर एक नवीन रूप प्रदान कर देता है।

इसे समझने के लिए तीन अवस्थाओं की कल्पना कीजिए:

  1. सजातीय ध्वनियों का विलय (दीर्घ स्वर सन्धि): जब दो समान स्वर मिलते हैं, तो मुख की मांसपेशियाँ एक लम्बा खिंचाव लेती हैं (a+a→aˉa + a \to \bar{a}a+a→aˉ)। जैसे—हिम + आलय = हिमालय; विद्या + अर्थी = विद्यार्थी।
  2. विजातीय ध्वनियों का संकरण (गुण एवं वृद्धि सन्धि): कंठ ध्वनि (अ/आ) जब तालु ध्वनि (इ/ई) से मिलती है, तो दोनों के बीच का बिंदु 'ए' (कंठ-तालव्य) बन जाता है। जब कंठ ध्वनि ओष्ठ ध्वनि (उ/ऊ) से मिलती है, तो 'ओ' (कंठोष्ठ्य) बन जाता है। वृद्धि सन्धि में यह एक पायदान और आगे बढ़कर क्रमशः 'ऐ' और 'औ' में परिणत हो जाता है।
  3. अर्धस्वर में संक्रमण (यण एवं अयादि सन्धि): जब मुख पहले संकीर्ण स्वर (इ या उ) पर हो और अचानक खुले स्वर की ओर गति करे, तो स्वर घिसटकर अर्धस्वर 'य्' या 'व्' बन जाता है। (उदा. इ + आ = 'या' →\to→ इति + आदि = इत्यादि)।
Core Principle

स्वर सन्धि के पाँचों भेदों के प्रामाणिक नियम, सूत्र एवं वर्गीकृत उदाहरण सारणी

1. दीर्घ स्वर सन्धि (अकः सवर्णे दीर्घः)

नियम: ह्रस्व या दीर्घ अ, इ, उ, ऋ के बाद क्रमशः समान ह्रस्व या दीर्घ अ, इ, उ, ऋ आएँ तो दोनों मिलकर दीर्घ आ, ई, ऊ, ॠ हो जाते हैं।

सन्धि प्रकार संघटक स्वर सामासिक पद (सन्धि रूप) प्रामाणिक विच्छेद अर्थ संदर्भ
अ/आ + अ/आ = आ अ + अ दैत्यारि दैत्य + अरि दैत्यों का शत्रु (विष्णु)
अ + आ प्रांगण प्र + अंगण खुला विस्तृत आँगन
आ + अ परीक्षार्थी परीक्षा + अर्थी परीक्षा चाहने वाला
आ + आ दयानन्द दया + आनन्द दया में आनंदित
इ/ई + इ/ई = ई इ + इ कवीन्द्र कवि + इन्द्र कवियों में श्रेष्ठ
इ + ई कपीश कपि + ईश वानरों के स्वामी (हनुमान/सुग्रीव)
ई + इ महीन्द्र मही + इन्द्र पृथ्वी का स्वामी (राजा)
ई + ई सतीश सती + ईश सती के पति (शिव)
उ/ऊ + उ/ऊ = ऊ उ + उ भानूदय भानु + उदय सूर्य का निकलना
उ + ऊ लघूर्मि लघु + ऊर्मि छोटी लहर
ऊ + उ चमूत्थान चमू + उत्थान सेना का उठना/प्रयाण
ऊ + ऊ भूष्मा भू + ऊष्मा पृथ्वी की गरमी
ऋ + ऋ = ॠ ऋ + ऋ पितॄण पितृ + ऋण पिता का ऋण

2. गुण स्वर सन्धि (आद्गुणः)

नियम: यदि 'अ/आ' के बाद 'इ/ई' आए तो दोनों मिलकर 'ए', 'उ/ऊ' आए तो 'ओ', तथा 'ऋ' आए तो 'अर्' हो जाता है।

संघटक रूप सन्धि पद शुद्ध विच्छेद परीक्षा में होने वाला अशुद्ध विच्छेद (Trap)
अ/आ + इ/ई = ए गुडाकेश गुडाका + ईश गुडा + केश (गलत; गुडाका = निद्रा, ईश = स्वामी अर्थात् अर्जुन/शिव)
राकेश राका + ईश राक + ईश (गलत; राका = पूर्णिमा की रात)
यथेष्ट यथा + इष्ट यथा + ईष्ट (गलत; इष्ट में ह्रस्व 'इ' होता है)
अ/आ + उ/ऊ = ओ जलोर्मि जल + ऊर्मि जल + उर्मि (गलत; ऊर्मि में दीर्घ 'ऊ' होता है)
नवोढ़ा नव + ऊढ़ा नव + ओढ़ा / नव + उढ़ा (गलत; ऊढ़ा = विवाहिता)
शीतोष्ण शीत + उष्ण शीत + ऊष्ण (गलत; उष्ण में ह्रस्व 'उ')
अ/आ + ऋ = अर् महर्षि महा + ऋषि मह + ऋषि (गलत; मूल शब्द 'महा' है)
वर्षर्तु वर्षा + ऋतु वर्ष + ऋतु (गलत; वर्षा की ऋतु)
शीतर्तु शीत + ऋतु शीत की ऋतु

3. वृद्धि स्वर सन्धि (वृद्धिरेचि)

नियम: यदि 'अ/आ' के बाद 'ए/ऐ' आए तो दोनों मिलकर 'ऐ' (दो मात्राएं: ै), और यदि 'ओ/औ' आए तो दोनों मिलकर 'औ' (ौ) हो जाते हैं।

संघटक रूप सन्धि पद शुद्ध विच्छेद परीक्षक जाल / शुद्ध वर्तनी टिप्पणी
अ/आ + ए/ऐ = ऐ मतैक्य मत + ऐक्य मत + एक्य (एक्य अशुद्ध है; 'एक' में 'य' प्रत्यय से 'ऐक्य' बनता है)
महैश्वर्य महा + ऐश्वर्य ईश्वर + य = ऐश्वर्य
सदैव सदा + एव एव = ही
वसुधैव वसुधा + एव वसुधा = पृथ्वी
अ/आ + ओ/औ = औ जलौघ जल + ओघ ओघ = प्रवाह / वेग
महौषध महा + औषध औषध में 'औ' की मात्रा होती है
महौदार्य महा + औदार्य उदार + य = औदार्य
दन्तोष्ठ दन्त + ओष्ठ (अपवाद स्वरूप 'दन्तौष्ठ' और 'दन्तोष्ठ' दोनों शुद्ध मान्य)

4. यण स्वर सन्धि (इको यणचि)

नियम: यदि पूर्व पद के अंत में इ/ई, उ/ऊ, ऋ हो और परे कोई असमान स्वर आए, तो:

  • इ/ई $ o$ य्
  • उ/ऊ $ o$ व्
  • ऋ $ o$ र्
सन्धि पद घटक विच्छेद रूपान्तरण प्रक्रिया अर्थ / टिप्पणी
अध्येषणा अधि + एषणा अधि (ध् + इ) + एषणा $ o$ अध् + य् + एषणा $ o$ अध्येषणा खोज, अनुसंधान
व्यूह वि + ऊह वि (व् + इ) + ऊह $ o$ व् + य् + ऊह $ o$ व्यूह सैन्य रचना
प्रत्युपकार प्रति + उपकार प्रति (त् + इ) + उपकार $ o$ प्रत् + य् + उपकार $ o$ प्रत्युपकार उपकार के बदले उपकार
अन्वय अनु + अय अनु (न् + उ) + अय $ o$ अन् + व् + अय $ o$ अन्वय व्याकरणिक संगति
मध्वरी मधु + अरि मधु (ध् + उ) + अरि $ o$ मध् + व् + अरि $ o$ मध्वरी श्रीकृष्ण (मधु राक्षस के शत्रु)
गुरवज्ञा गुरु + अवज्ञा गुरु (र् + उ) + अवज्ञा $ o$ गुर् + व् + अवज्ञा $ o$ गुरवज्ञा गुरु की अवहेलना
पित्रनुमति पितृ + अनुमति पितृ (त् + ऋ) + अनुमति $ o$ पत् + र् + अनुमति $ o$ पित्रनुमति पित्रा + अनुमति अशुद्ध है!
मात्राज्ञा मातृ + आज्ञा मातृ (त् + ऋ) + आज्ञा $ o$ पत् + र् + आज्ञा $ o$ मात्राज्ञा माता की आज्ञा

5. अयादि स्वर सन्धि (एचोऽयवायावः)

नियम: यदि पूर्व पद के अंत में ए, ऐ, ओ, औ हो और परे कोई भी स्वर आए, तो:

  • ए $ o$ अय्
  • ऐ $ o$ आय्
  • ओ $ o$ अव्
  • औ $ o$ आव्
सन्धि पद शुद्ध विच्छेद परिवर्तन सूत्र परीक्षा टिप्पणी
नयन ने + अन न् + ए + अन $ o$ न् + अय् + अन $ o$ नयन आँख
नायक नै + अक न् + ऐ + अक $ o$ न् + आय् + अक $ o$ नायक नेता, अभिनेता
पवन पो + अन प् + ओ + अन $ o$ प् + अव् + अन $ o$ पवन वायु
पावक पौ + अक प् + औ + अक $ o$ प् + आव् + अक $ o$ पावक अग्नि
गवेषणा गो + एषणा ग् + ओ + एषणा $ o$ ग् + अव् + एषणा $ o$ गवेषणा गहन शोध (गायों की खोज से विकसित)
गव्य गो + य ओ का अव् (वान्तो यि प्रत्यये सूत्र) $ o$ ग् + अव् + य = गव्य गाय का दुग्ध आदि
भावुक भौ + उक भ् + औ + उक $ o$ भ् + आव् + उक $ o$ भावुक संवेदनशील
नाविक नौ + इक न् + औ + इक $ o$ न् + आव् + इक $ o$ नाविक मल्लाह
Mechanism & Operational Rule

स्वर-सन्धि की रूप-ध्वन्यात्मक समीकरण प्रणाली एवं अपवाद विधान

स्वर सन्धि की गणितीय संरचना को निम्नांकित समीकरणों द्वारा समझा जा सकता है:

1. यण सन्धि का परिवर्तन-चरण (Step-by-Step Morpho-phonemic Resolution):

अति+आचार→वर्ण-वियोजन[अ+त्+इ]+[आ+च्+आ+र्+अ]\text{अति} + \text{आचार} \xrightarrow{\text{वर्ण-वियोजन}} [अ + त् + इ] + [आ + च् + आ + र् + अ]अति+आचारवर्ण-वियोजन​[अ+त्+इ]+[आ+च्+आ+र्+अ]
→इ+आ  ⟹  य्+आ=याअ+त्+या+च्+आ+र्+अ  ⟹  अत्याचार\xrightarrow{इ + आ \implies य् + आ = या} अ + त् + या + च् + आ + र् + अ \implies \mathbf{अत्याचार}इ+आ⟹य्+आ=या​अ+त्+या+च्+आ+र्+अ⟹अत्याचार

2. पितृ / मातृ आधारित यण सन्धि का शुद्धीकरण:

पितृ+उपदेश→त्+ऋ+उत्+र्+उ  ⟹  त्रु  ⟹  पित्रुपदेश\text{पितृ} + \text{उपदेश} \xrightarrow{त् + ऋ + उ} त् + र् + उ \implies \mathbf{त्रु} \implies \mathbf{पित्रुपदेश}पितृ+उपदेशत्+ऋ+उ​त्+र्+उ⟹त्रु⟹पित्रुपदेश
(परीक्षक ट्रैप: छात्र 'पित्रापदेश' या 'पितृपदेश' लिख देते हैं, जो शून्य अंक दिलाता है)

3. अयादि सन्धि एवं वान्तो यि प्रत्यये नियम:

यदि 'ओ' अथवा 'औ' के अनन्तर 'य' प्रत्यय आए (यथा य-कारादि प्रत्यय), तो भी ओ का 'अव्' और औ का 'आव्' हो जाता है:

  • गो+य→ग्+अव्+य=गव्य\text{गो} + \text{य} \to \text{ग्} + \text{अव्} + \text{य} = \mathbf{गव्य}गो+य→ग्+अव्+य=गव्य
  • नौ+य→न्+आव्+य=नाव्य\text{नौ} + \text{य} \to \text{न्} + \text{आव्} + \text{य} = \mathbf{नाव्य}नौ+य→न्+आव्+य=नाव्य (नौका से पार करने योग्य)

4. गुण-वृद्धि के प्रमुख शास्त्रीय अपवाद (वार्तिक नियम):

  • अक्ष + ऊहिनी = अक्षौहिणी (नियमतः गुण से 'अक्षोहिणी' होना चाहिए था, किन्तु वार्तिक से वृद्धि होकर 'अक्षौहिणी' बनता है — चतुरंगिणी सेना)।
  • प्र + ऊढ़ = प्रौढ़ (गुण का अपवाद →\to→ वृद्धि होकर 'प्रौढ़' बनता है)।
  • प्र + ऊह = प्रौह; प्र + ऊढ़ि = प्रौढ़ि।
  • सुख + ऋत = सुखार्त (सुखार्त = सुख से आर्त; तृतीया तत्पुरुष समास में 'ऋते च तृतीयासमासे' वार्तिक से 'अर्' के स्थान पर 'आर्' वृद्धि होती है)।
Exam Application & Traps

RPSC RAS Mains Paper IV — परीक्षक के प्रिय प्रश्न, वर्तनी जाल एवं विच्छेद रणनीति

RPSC RAS Mains में सन्धि-विच्छेद करने के स्वर्णिम नियम:

  1. अर्थवान मूल शब्दों की पहचान:
    विच्छेद करते समय दोनों शब्द पूर्णतः सार्थक होने चाहिए।

    • अशुद्ध विच्छेद: अभ्यार्थी →\to→ छात्र लिख देते हैं 'अभ्या + अर्थी'।
    • शुद्ध विच्छेद: अभि + अर्थी = अभ्यर्थी (यण सन्धि)। अतः शब्द भी 'अभ्यर्थी' शुद्ध है, 'अभ्यार्थी' अशुद्ध है!

  2. मात्रा-भेद जाल (ह्रस्व बनाम दीर्घ):

    • ईश, ईश्वर, ईक्षण, ईहा, ईप्सित, ऊर्जा, ऊर्मि, ऊढ़ा: इनमें सदैव दीर्घ स्वर (ई, ऊ) होता है।
      • कपीश = कपि + ईश
      • जलोर्मि = जल + ऊर्मि
      • नवोढ़ा = नव + ऊढ़ा
      • प्रतीक्षक = प्रति + ईक्षक
    • इन्द्र, इष्ट, उत्सव, उदय, उपकार, उत्तम, अनुमति: इनमें सदैव ह्रस्व स्वर (इ, उ) होता है।
      • रवीन्द्र = रवि + इन्द्र
      • यथेष्ट = यथा + इष्ट
      • महोत्थान = महा + उत्थान

  3. 'ऐ' और 'औ' वाले वृद्धि सन्धि शब्दों का विच्छेद:

    • मतैक्य = मत + ऐक्य (न कि एक्य)
    • महैश्वर्य = महा + ऐश्वर्य (न कि ऐश्वर्य में ह्रस्व)
    • वनौषधि = वन + ओषधि (ओषधि में ओ तथा औषध में औ मान्य है)

  4. गवाक्ष का विशेष विवाद:

    • 'गवाक्ष' (खिड़की/झरोखा) का विच्छेद गो + अक्ष (अवादेश होकर) माना जाता है। दीर्घ सन्धि के अनुसार 'गव + अक्ष' भी कई पुस्तकों में मिलता है, किन्तु RPSC मानक संस्कृत वार्तिक 'सर्वत्र गोः' के अनुसार गो + अक्ष को प्राथमिकता देती है।

सन्धि एवं सन्धि-विच्छेद · Concept 2 of 2

सन्धि एवं सन्धि-विच्छेद — व्यंजन सन्धि एवं विसर्ग सन्धि के प्रमुख नियम व अपवाद

व्यंजन के साथ व्यंजन या स्वर के मेल से उत्पन्न विकार (जश्त्व, श्चुत्व, च-आगम, अनुनासिकता, मूर्धन्यीकरण) तथा विसर्ग (:) का ओ, र्, श्, ष्, स् अथवा विलोप में रूपान्तरण एवं अहन्-सम्बन्धी अपवाद।

Intuition & Context

व्यंजन एवं विसर्ग सन्धि का आत्मसात्करण: मुख सुख और संकोच का ध्वन्यात्मक नियम

जब दो कठोर पत्थर आपस में टकराते हैं तो एक पत्थर दूसरे के किनारे को तोड़कर समतल बना देता है। व्यंजन और विसर्ग सन्धि की यही मूल आत्मा है जिसे भाषाविज्ञान में 'समीकरण' (Assimilation) कहा जाता है।

  1. सघोषीकरण (Voicing): अघोष व्यंजन (क्, त्) जब सघोष वायु (स्वर या ग, द) के संपर्क में आते हैं, तो वाग्-तंत्री में स्वतः कंपन शुरू हो जाता है, जिससे 'क्' कठोर न रहकर कोमल 'ग्' में और 'त्' कोमल 'द्' में ढल जाता है। (वाक् + जाल = वाग्जाल)।
  2. अनुनासिकीकरण (Nasalization): जब आगे पंचमाक्षर (म् या न्) आ रहा हो, तो मुख-विवर पहले से ही नाक का रास्ता खोल देता है, जिससे प्रथम वर्ण सीधे अपने वर्ग के नासिक्य में कूद जाता है। (वाक् + मय = वाङ्मय; षट् + मास = षण्मास)।
  3. विसर्ग की तरलता: विसर्ग (ः) मूलतः संस्कृत की श्वास-ध्वनि है जो अंतःस्थित 'स्' या 'र्' का अवशिष्ट रूप है। अनुकूल वातावरण मिलते ही यह पुनः अपने मूल रूप 'र्', तालव्य 'श्', मूर्धन्य 'ष्' अथवा दन्त्य 'स्' में लौट आती है।
Core Principle

व्यंजन एवं विसर्ग सन्धि के सम्पूर्ण प्रामाणिक नियम एवं उदाहरण तालिका

1. व्यंजन सन्धि के प्रमुख 10 नियम

(क) वर्ग के प्रथम वर्ण का तीसरे वर्ण में परिवर्तन (जश्त्व विधान)

  • सूत्र: क्, च्, ट्, त्, प् + सघोष वर्ण (स्वर, वर्ग 3, 4, य, र, ल, व, ह) →\to→ ग्, ज्, ड्, द्, ब्
  • उदा.:
    • दिक् + अम्बर = दिगम्बर
    • वाक् + देवी = वाग्देवी
    • अच् + आदि = अजादि
    • षट् + दर्शन = षड्दर्शन
    • तत् + रूप = तद्रूप
    • अप् + द = अब्द (बादल); अप् + ज = अब्ज (कमल)

(ख) वर्ग के प्रथम वर्ण का पंचमाक्षर में परिवर्तन (अनुनासिक विधान)

  • सूत्र: क्, ट्, त्, प् + न् / म् →\to→ ङ्, ण्, न्, म्
  • उदा.:
    • वाक् + मय = वाङ्मय (वाङ्गमय अशुद्ध है!)
    • षट् + मास = षण्मास
    • षट् + मूर्ति = षण्मूर्ति
    • तत् + मय = तन्मय
    • उत् + नति = उन्नति
    • मृत् + मय = मृन्मय
    • अप् + मय = अम्मय

(ग) 'त्' सम्बन्धी विशिष्ट परिवर्तन नियम

  1. त् + च / छ →\to→ च्च / च्छ (उत् + चारण = उच्चारण; शरत् + चन्द्र = शरच्चन्द्र)
  2. त् + ज / झ →\to→ ज्ज (सत् + जन = सज्जन; विपत् + जाल = विपज्जाल; उत् + ज्वल = उज्ज्वल — दोनों 'ज' आधे!)
  3. त् + ट / ठ →\to→ ट्ट (तत् + टीका = तट्टीका; बृहत् + टीका = बृहट्टीका)
  4. त् + ड / ढ →\to→ ड्ड (उत् + डयन = उड्डयन)
  5. त् + ल →\to→ ल्ल (उत् + लास = उल्लास; तत् + लीन = तल्लीन)
  6. त् + श →\to→ च्छ (उत् + श्वास = उच्छ्वास; उत् + शृंखल = उच्छृंखल; सत् + शास्त्र = सच्छास्त्र)
  7. त् + ह →\to→ द्ध (उत् + हार = उद्धार; तत् + हित = तद्धित; पद् + हति = पद्धति)

(घ) 'छ' सम्बन्धी च-आगम नियम

ह्रस्व स्वर के बाद 'छ' आए तो बीच में 'च्' का आगम होता है:

  • परि + छेद = परिच्छेद
  • अनु + छेद = अनुच्छेद
  • वि + छेद = विच्छेद
  • स्व + छंद = स्वच्छंद
  • मातृ + छाया = मातृच्छाया (मातृछाया अशुद्ध है)

(ङ) 'म्' सम्बन्धी नियम (अनुस्वार विधान)

  1. म् + स्पर्श व्यंजन (क से म) →\to→ परसवर्ण (पंचमाक्षर) अथवा अनुस्वार (ं)
    • सम् + कल्प = संकल्प / सङ्कल्प
    • सम् + तोष = संतोष / सन्तोष
    • सम् + पूर्ण = संपूर्ण / सम्पूर्ण
  2. म् + अंतःस्थ या ऊष्म (य, र, ल, व, श, ष, स, ह) →\to→ केवल अनुस्वार (ं)
    • सम् + योग = संयोग
    • सम् + रक्षण = संरक्षण
    • सम् + वाद = संवाद
    • सम् + हार = संहार

(च) मूर्धन्यीकरण नियम (स् का ष् होना)

'अ/आ' से भिन्न स्वर के बाद 'स्' आए तो 'स्' का 'ष्' हो जाता है:

  • अभि + सेक = अभिषेक
  • वि + सम = विषम
  • सु + सुप्ति = सुषुप्ति
  • नि + सिद्ध = निषिद्ध
  • अनु + संगी = अनुषंगी

(छ) 'न्' का 'ण्' में परिवर्तन

एक ही पद में यदि ऋ, र्, ष् के बाद 'न्' आए तो 'न्' का 'ण्' हो जाता है (चाहे बीच में स्वर, क-वर्ग, प-वर्ग का व्यवधान हो):

  • परि + नाम = परिणाम
  • प्र + मान = प्रमाण
  • राम + अयन = रामायण (दीर्घ स्वर + न का ण दोनों)
  • कृष् + न = कृष्ण
  • शूर्प + नखा = शूर्पणखा

Mechanism & Operational Rule

व्यंजन-विसर्ग रूप-परिवर्तन की ध्वन्यात्मक यंत्रणा एवं अहन्-नियम का विश्लेषण

1. 'उज्ज्वल' और 'उच्छ्वास' का निर्माण तंत्र:

  • उज्ज्वल:
    उत्+ज्वल→त्+ज  ⟹  ज्जउ+ज्+ज्वल=उज्ज्वल\text{उत्} + \text{ज्वल} \xrightarrow{त् + ज \implies ज्ज} \text{उ} + \text{ज्} + \text{ज्वल} = \mathbf{उज्ज्वल}उत्+ज्वलत्+ज⟹ज्ज​उ+ज्+ज्वल=उज्ज्वल

    उत्+श्वास→त्→च्,  श्→छ्उ+च्+छ्वास=उच्छ्वास\text{उत्} + \text{श्वास} \xrightarrow{त् \to च्,; श् \to छ्} \text{उ} + \text{च्} + \text{छ्वास} = \mathbf{उच्छ्वास}उत्+श्वासत्→च्,श्→छ्​उ+च्+छ्वास=उच्छ्वास

2. 'अहन्' शब्द की विसर्ग-प्रक्रिया (Phonological Split):

'अहन्' (दिन) के साथ सन्धि के दो सर्वथा विपरीत नियम कार्य करते हैं:

  1. यदि परवर्ती वर्ण 'र' न हो: अहन् का विसर्ग होकर 'ओ' बन जाता है:
    • अहन्+मुख→अहोमुख\text{अहन्} + \text{मुख} \to \mathbf{अहोमुख}अहन्+मुख→अहोमुख
    • अहन्+रूप→अहोरूप\text{अहन्} + \text{रूप} \to \mathbf{अहोरूप}अहन्+रूप→अहोरूप
    • अहन्+रात्र→अहोरात्र\text{अहन्} + \text{रात्र} \to \mathbf{अहोरात्र}अहन्+रात्र→अहोरात्र (अहोरात्री अशुद्ध है!)
  2. यदि परवर्ती वर्ण 'र' हो: रो-री सूत्र से द्वित्व के भय से अहन् का 'अहर्' हो जाता है:
    • अहन्+अहन्→अहरह\text{अहन्} + \text{अहन्} \to \mathbf{अहरह}अहन्+अहन्→अहरह (दिन-प्रतिदिन)
    • अहन्+निश→अहर्निश\text{अहन्} + \text{निश} \to \mathbf{अहर्निश}अहन्+निश→अहर्निश (दिन-रात)
    • अहन्+पति→अहर्पति\text{अहन्} + \text{पति} \to \mathbf{अहर्पति}अहन्+पति→अहर्पति (सूर्य)

3. अधःपतन बनाम मनोबल का विभेदक समीकरण:

  • मनः+बल→′ब′=सघोषमनोबल\text{मनः} + \text{बल} \xrightarrow{'ब' = \text{सघोष}} \mathbf{मनोबल}मनः+बल′ब′=सघोष​मनोबल (विसर्ग का 'ओ')
  • अधः+पतन→′प′=अघोषअधःपतन\text{अधः} + \text{पतन} \xrightarrow{'प' = \text{अघोष}} \mathbf{अधःपतन}अधः+पतन′प′=अघोष​अधःपतन (विसर्ग सुरक्षित रहेगा; 'अधोपतन' व्याकरण सम्मत नहीं है!)
Exam Application & Traps

RPSC RAS Mains Paper IV — परीक्षक के घातक ट्रैप, शब्द-शुद्धि सह-सम्बन्ध एवं प्राप्तांक कुंजियाँ

RPSC RAS Mains Paper IV व्यंजन व विसर्ग सन्धि के घातक ट्रैप:

  1. 'अधोपतन' एवं 'मनोकामना' की अशुद्धि:

    • छात्र धड़ल्ले से 'मनोकामना' बोलते हैं, किन्तु व्याकरण सम्मत शुद्ध शब्द मनःकामना (मनः + कामना) है क्योंकि 'क' अघोष है।
    • इसी प्रकार अधःपतन (अधः + पतन) शुद्ध है, 'अधोपतन' अशुद्ध है।
    • प्रातःकाल, पयःपान, अंतःकरण में विसर्ग सदैव सुरक्षित रहता है।

  2. 'नीरोग' एवं 'नीरस' की वर्तनी:

    • 'निः + रोग' में विसर्ग का लोप होकर पूर्व स्वर 'इ' दीर्घ होकर 'ई' बन जाता है।
    • अतः नीरोग शुद्ध है; परीक्षा में 'निरोग' लिखना वर्तनी अशुद्धि माना जाएगा।

  3. 'वाङ्मय' का शुद्ध विच्छेद:

    • शब्द: वाङ्मय →\to→ विच्छेद: वाक् + मय।
    • छात्र प्रायः 'वाङ् + मय' या 'वांग + मय' लिख देते हैं, जिससे शून्य अंक मिलता है। प्रथम पद सदैव वर्ग का प्रथम वर्ण (क्) हलन्त युक्त होना चाहिए।

  4. 'उच्छृंखल' का विच्छेद:

    • शुद्ध विच्छेद: उत् + शृंखल (त् का च् और शृ का छृ)।

  5. 'शिरोभाग' एवं 'वयःक्रम':

    • शिरः + भाग = शिरोभाग (भा सघोष है)
    • शिरः + छेद = शिरच्छेद (च परे होने से विसर्ग का श्)
    • मनः + चिकित्सा = मनश्चिकित्सा (मनोचिकित्सा अशुद्ध है!)

    • प्रथम वर्ण →+न/म5\xrightarrow{+ न/म} 5+न/म​5th (ङ, ञ, ण, न, म) [वाक् + मय = वाङ्मय]
  3. त्-कार बहुआयामी नोड्स:
    • त् + श् →\to→ च्छ (उच्छृंखल)
    • त् + ह् →\to→ द्ध (पद्धति)
    • त् + ज् →\to→ ज्ज (सज्जन)
    • त् + ल् →\to→ ल्ल (उल्लेख)
  4. विसर्ग (ः) त्रि-मार्गी विन्यास:
    • ओ-मार्ग: अ + ः + सघोष →\to→ ओ (तपोबल = तपः + बल)
    • र्-मार्ग: इ/उ + ः + सघोष →\to→ र् (निराशा = निः + आशा)
