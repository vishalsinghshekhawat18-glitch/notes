12:T60c,The **Système International d'Unités (SI)** anchors all physical measurement across science:

| Base Physical Quantity | Base Unit Name | Symbol | Defining Physical Anchor |
| :--- | :--- | :---: | :--- |
| **Length** | Metre | $\text{m}$ | Distance light travels in vacuum in $1/299,792,458$ seconds. |
| **Mass** | Kilogram | $\text{kg}$ | Defined via fixed Planck constant ($h = 6.62607015 \times 10^{-34} \, \text{J}\cdot\text{s}$). |
| **Time** | Second | $\text{s}$ | Duration of $9,192,631,770$ periods of Caesium-133 radiation. |
| **Electric Current** | Ampere | $\text{A}$ | Elementary charge ($e = 1.602176634 \times 10^{-19} \, \text{C}$). |
| **Thermodynamic Temperature** | Kelvin | $\text{K}$ | Boltzmann constant ($k = 1.380649 \times 10^{-23} \, \text{J/K}$). |
| **Amount of Substance** | Mole | $\text{mol}$ | Exactly $6.02214076 \times 10^{23}$ elementary entities ($N_A$). |
| **Luminous Intensity** | Candela | $\text{cd}$ | Monochromatic radiation of frequency $540 \times 10^{12} \, \text{Hz}$. |

### High-Yield Derived SI Units Table
- **Force**: Newton ($\text{N}$) $= \text{kg}\cdot\text{m/s}^2$
- **Work / Energy / Heat**: Joule ($\text{J}$) $= \text{N}\cdot\text{m} = \text{kg}\cdot\text{m}^2/\text{s}^2$
- **Power**: Watt ($\text{W}$) $= \text{J/s} = \text{kg}\cdot\text{m}^2/\text{s}^3$
- **Pressure / Stress**: Pascal ($\text{Pa}$) $= \text{N/m}^2 = \text{kg}/(\text{m}\cdot\text{s}^2)$
- **Electric Potential**: Volt ($\text{V}$) $= \text{W/A} = \text{J/C}$
- **Frequency**: Hertz ($\text{Hz}$) $= \text{s}^{-1}$13:T520,### 1. Vernier Calliper Formula
$$\text{Least Count (LC)} = 1 \, \text{MSD} - 1 \, \text{VSD} = \frac{\text{Value of 1 Main Scale Division}}{\text{Total Number of Vernier Divisions } (n)}$$
- If $1 \, \text{MSD} = 1 \, \text{mm}$ and $n = 10$, then $\text{LC} = \frac{1 \, \text{mm}}{10} = 0.1 \, \text{mm} = 0.01 \, \text{cm}$.
$$\text{Total Reading} = \text{Main Scale Reading (MSR)} + (\text{Vernier Coincidence} \times \text{LC}) - (\pm \text{Zero Error})$$

### 2. Screw Gauge Formula
$$\text{Pitch} = \frac{\text{Distance moved on main linear scale}}{\text{Number of complete rotations}}$$
$$\text{Least Count (LC)} = \frac{\text{Pitch}}{\text{Total number of Circular Scale Divisions}}$$
- If $\text{Pitch} = 1 \, \text{mm}$ and circular scale has $100$ divisions, $\text{LC} = \frac{1 \, \text{mm}}{100} = 0.01 \, \text{mm} = 0.001 \, \text{cm} = 10 \, \mu\text{m}$.

### 3. Zero Error Correction Rules
- **Positive Zero Error**: Zero of vernier/circular scale lies to the *right/above* reference line $\implies$ Instrument reads excess $\implies$ **Subtract error from observed reading**.
- **Negative Zero Error**: Zero lies to the *left/below* $\implies$ Instrument reads deficit $\implies$ **Add magnitude of error to observed reading** (or $\text{True Reading} = \text{Observed} - (-\text{Error})$).14:T47f,### 1. Atomic Scale Units
- **Angstrom ($\text{Å}$)**: $1 \, \text{Å} = 10^{-10} \, \text{m} = 0.1 \, \text{nm}$ (Used for atomic radius and light wavelengths).
- **Fermi / Femtometre ($\text{fm}$)**: $1 \, \text{fm} = 10^{-15} \, \text{m}$ (Nuclear size order).
- **Atomic Mass Unit ($u$ / Dalton)**: $1 \, u = 1.66054 \times 10^{-27} \, \text{kg}$ ($1/12\text{th}$ mass of C-12 atom).

### 2. Astronomical Scale Units (Order of Increasing Size)
$$\text{Astronomical Unit (AU)} < \text{Light Year (ly)} < \text{Parsec (pc)}$$
- **Astronomical Unit (AU)**: Average distance between Earth and Sun $= 1.496 \times 10^{11} \, \text{m} \approx 150 \text{ million km}$.
- **Light Year (ly)**: Distance light travels in vacuum in 1 Julian year ($365.25 \times 86400 \, \text{s} \times 3 \times 10^8 \, \text{m/s}$):
  $$1 \, \text{ly} = 9.46 \times 10^{15} \, \text{m} \approx 9.46 \text{ trillion km}$$
- **Parsec (Parallactic Second)**: Distance at which an astronomical unit subtends an angle of 1 arcsecond ($1''$):
